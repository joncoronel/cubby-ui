Resizable splits a layout into panels with draggable handles between them. Use it for split editors, a sidebar beside content, or any pane layout your users should size themselves.

## Composition

```text
ResizablePanelGroup
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```

Place a `ResizableHandle` between each pair of panels.

## Features

- Collapse, expand, `resize()`, `setLayout()`, keyboard steps and a double-click reset ease over 320ms; drags track the pointer 1:1.
- Set `--resizable-duration` on the group to retune the easing, or `0ms` to turn it off. Reduced motion turns it off too.
- Double-click a handle to reset its panel to its default size.
- Panels clip content along the resize axis instead of showing a scrollbar, and scroll along the other.
- Size the group with ordinary classes such as `h-64`.

## Sizes

Size props take a number or a string, and the two mean different things.

| Value     | Meaning                                   |
| --------- | ----------------------------------------- |
| `200`     | Pixels                                    |
| `"30%"`   | Percent of the group                      |
| `"30"`    | Percent (a string with no unit)           |
| `"12rem"` | Any of `px`, `%`, `em`, `rem`, `vh`, `vw` |

<Callout type="warn">
  `defaultSize={50}` is 50px wide, not half the group. Write `defaultSize="50%"`
  for a percentage.
</Callout>

<Callout type="warn">
  The hook reads `localStorage` while rendering, so it crashes on the server.
  Pass a no-op `storage` until hydration and remount the group once the saved
  layout is readable, as the example does. For no layout shift at all, store the
  layout in a cookie and read it on the server.
</Callout>

## Accessibility

Each handle is a `separator` in the tab order, with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.

| Key            | Action                                                    |
| -------------- | --------------------------------------------------------- |
| Arrow keys     | Resize by 5%                                              |
| `Home` / `End` | Resize to the minimum or maximum                          |
| `Enter`        | Collapse or expand the panel before the handle, if it can |
| `F6`           | Move focus to the next handle                             |

Clicking a handle focuses it, so the arrow keys work straight after.

## API Reference

Resizable is built on [react-resizable-panels](https://react-resizable-panels.vercel.app) v4. All of its props are supported. The documentation below covers custom props, changed behavior, and the props you need most. `usePanelRef`, `useGroupRef`, `useGridRef`, `useDefaultLayout` and `useDefaultGridLayout` are re-exported from the same module.

For the complete API, see the [react-resizable-panels documentation](https://react-resizable-panels.vercel.app).

### Props

#### ResizablePanelGroup

Lays out panels and tracks their sizes. Wraps `Group`, minus its inline `height` and `width`, so sizing classes apply.

<ApiPropsList>

<ApiProp
  name="orientation"
  fullType='"horizontal" | "vertical"'
  simpleType="string"
  defaultValue='"horizontal"'
>
  Axis the panels resize along.
</ApiProp>

<ApiProp name="defaultLayout" fullType="{ [panelId: string]: number }">
  Initial sizes as percentages, keyed by panel `id`. Usually comes from
  `useDefaultLayout`.
</ApiProp>

<ApiProp
  name="onLayoutChanged"
  fullType="(layout: Layout, meta: LayoutChangedMeta) => void"
>
  Runs once a resize finishes. Use it to persist the layout; `onLayoutChange`
  runs on every pointer move instead.
</ApiProp>

</ApiPropsList>

#### ResizablePanel

One resizable region. Wraps `Panel`. `className` and `style` apply to the inner container, which clips along the resize axis; pass `style={{ overflow: "auto" }}` to scroll both ways.

<ApiPropsList>

<ApiProp name="defaultSize" fullType="number | string">
  Initial size. Numbers are pixels; strings are percentages unless they carry a
  unit.
</ApiProp>

<ApiProp name="minSize" fullType="number | string" defaultValue='"0%"'>
  Smallest size the panel can shrink to.
</ApiProp>

<ApiProp name="maxSize" fullType="number | string" defaultValue='"100%"'>
  Largest size the panel can grow to.
</ApiProp>

<ApiProp name="collapsible" fullType="boolean" defaultValue="false">
  Lets the panel snap to `collapsedSize` when dragged below `minSize`.
</ApiProp>

<ApiProp name="collapsedSize" fullType="number | string" defaultValue='"0%"'>
  Size of the collapsed panel.
</ApiProp>

<ApiProp name="collapsedThreshold" fullType="number | string">
  Distance past `minSize` before the panel collapses, and past `collapsedSize`
  before it expands. Defaults to half the gap between the two.
</ApiProp>

<ApiProp name="id" fullType="string | number">
  Identifies the panel in saved layouts. Required for `useDefaultLayout`.
</ApiProp>

<ApiProp name="panelRef" fullType="Ref<PanelImperativeHandle>">
  Exposes `collapse()`, `expand()`, `resize(size)`, `getSize()` and
  `isCollapsed()`.
</ApiProp>

</ApiPropsList>

#### ResizableHandle

Draggable divider between two panels. Wraps `Separator`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"line" | "grip" | "gap"'
  simpleType="string"
  defaultValue='"line"'
>
  Handle style. See the [variant table](#gap). Custom prop not available in
  react-resizable-panels.
</ApiProp>

</ApiPropsList>

#### ResizableGrid

Two-dimensional layout of cells. Wraps `Grid`, minus its inline `height` and `width`.

<ApiPropsList>

<ApiProp name="columns" fullType="number | GridTrackProps[]" required>
  Column count, or one set of constraints per column (`minSize`, `maxSize`,
  `collapsible` and the rest of the panel size props).
</ApiProp>

<ApiProp name="rows" fullType="number | GridTrackProps[]" required>
  Row count, or one set of constraints per row.
</ApiProp>

</ApiPropsList>

#### ResizableCell

One cell of a grid. Wraps `Cell` and clips its content on both axes; put a scroll container inside a cell that needs one.

<ApiPropsList>

<ApiProp name="column" fullType="number" required>
  Index of the first column the cell occupies.
</ApiProp>

<ApiProp name="row" fullType="number" required>
  Index of the first row the cell occupies.
</ApiProp>

<ApiProp name="columnSpan" fullType="number" defaultValue="1">
  Number of columns the cell spans.
</ApiProp>

<ApiProp name="rowSpan" fullType="number" defaultValue="1">
  Number of rows the cell spans.
</ApiProp>

</ApiPropsList>

#### ResizableGridline

Draggable line between two columns or two rows. Wraps `Gridline`, which forwards only `className`, `style`, `disabled`, `elementRef` and `children` besides the props below.

<ApiPropsList>

<ApiProp name="type" fullType='"column" | "row"' simpleType="string" required>
  Whether the line resizes columns or rows.
</ApiProp>

<ApiProp name="column" fullType="number">
  Required for a column line: the column it sits before. For a row line, the
  first column it spans. Defaults to `0`.
</ApiProp>

<ApiProp name="row" fullType="number">
  Required for a row line: the row it sits above. For a column line, the first
  row it spans. Defaults to `0`.
</ApiProp>

<ApiProp name="rowSpan" fullType="number">
  Column lines only. Rows the line spans; defaults to all rows from `row`. Use
  it to stop a line at a cell that spans across it.
</ApiProp>

<ApiProp name="columnSpan" fullType="number">
  Row lines only. Columns the line spans; defaults to all columns from `column`.
</ApiProp>

<ApiProp
  name="variant"
  fullType='"line" | "grip" | "gap"'
  simpleType="string"
  defaultValue='"line"'
>
  Same styles as `ResizableHandle`. Custom prop not available in
  react-resizable-panels.
</ApiProp>

</ApiPropsList>

## Migrating from v3

| v3                               | v4                                       |
| -------------------------------- | ---------------------------------------- |
| `direction="horizontal"`         | `orientation="horizontal"` (the default) |
| `defaultSize={30}`               | `defaultSize="30%"`                      |
| `<ResizableHandle withHandle />` | `<ResizableHandle variant="grip" />`     |
| `autoSaveId="layout"`            | `useDefaultLayout({ id: "layout" })`     |
| `onLayout`                       | `onLayoutChange` or `onLayoutChanged`    |
| `ref` on a panel                 | `panelRef`, typed with `usePanelRef()`   |
