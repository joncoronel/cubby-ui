The circular slider sets a value by dragging around a ring or turning a raised knob. Use it for dials where the circle means something: temperature, volume, an angle, or a window of hours on a clock face.

For a value on a straight line, use [Slider](/docs/components/slider) instead.

## Composition

`CircularSlider` is the ready-made ring. Compose the parts with `CircularSliderRoot` for ticks, a reference mark, a knob face, or your own center content.

```text
CircularSliderRoot
├── CircularSliderTrack
├── CircularSliderTicks
├── CircularSliderIndicator
├── CircularSliderMark
├── CircularSliderThumb
├── CircularSliderKnob
└── CircularSliderValue
```

## Features

- Clicks, `Home`/`End`/`Page` keys, and changes from outside sweep along the ring. Arrow steps and drags land at once, so a held key or a drag never trails.
- Grabbing a thumb holds it where it is. Clicking elsewhere on the band jumps the nearest thumb there.
- Pressing where a range's two thumbs overlap picks the one that can move the way you drag.
- Dragging past either end of a dial pins at that end instead of flipping to the other.
- Ticks change as the indicator's head passes them, not all at once.
- The middle of a ring ignores the pointer, so buttons and text placed there stay usable, and on touch a swipe that starts there scrolls the page. Only the band captures the gesture.
- A partial sweep is only as tall as its arc, so a 180° dial takes about half the height of a full one.

## Examples

### Thumb shape

Use `thumbShape` to choose the thumb's look. The pill reaches past both edges of the band, and the band moves in to make room so the dial keeps its size.

### Range

Pass an array of two values for a range. Drag the filled span to move both ends at once; on a `wrap` dial the span runs clockwise from the first value, through the seam. A thumb that runs into the other pushes it along, and when the two meet they merge into one pill. Set `thumbCollisionBehavior="none"` to stop at the other thumb instead, and `minStepsBetweenValues` to keep them apart.

## Accessibility

Each thumb is a visually hidden native `<input type="range">`, so it takes focus, joins forms, and announces as a slider. Name it with `aria-label` on the root, or with `getAriaLabel` for each thumb of a range, and pass `getAriaValueText` when the number alone doesn't say enough ("21.5 degrees", "07:00").

### Keyboard

| Key                     | Action                 |
| ----------------------- | ---------------------- |
| `↑` / `→`               | Increase by `step`.    |
| `↓` / `←`               | Decrease by `step`.    |
| `Shift` + arrow         | Change by `largeStep`. |
| `Page Up` / `Page Down` | Change by `largeStep`. |
| `Home` / `End`          | Jump to `min` / `max`. |

On a `wrap` dial the arrow keys loop past the ends, and `End` stops one step short of `max`, which shares `min`'s position.

## API Reference

The Circular Slider is a custom SVG component. It follows Base UI's patterns: every part renders through `useRender`, so each accepts a `render` prop.

### Props

#### CircularSliderRoot

Holds the value and geometry, and renders a hidden range input per thumb. `CircularSlider` takes the same props plus `formatValue`.

<ApiProp name="thickness" fullType="number" defaultValue="12">
