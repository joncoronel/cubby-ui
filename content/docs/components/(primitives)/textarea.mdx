A textarea collects multi-line text that grows with its content. Use it for comments, messages, or descriptions; for a single line such as a name or email, use [`Input`](/docs/components/input) instead.

### Outline Variant

`default` is a filled translucent tint that reads on the page, a Card, a Dialog, or a popover alike, so the field never needs a per-surface switch. Use `variant="outline"` when you want the outline Button's fill and edge instead: a card fill with a hairline border in light mode, and a recessed fill with a faint ring in dark mode.

<ComponentPreview component="textarea" example="textarea-outline" />

| Variant   | Description                                          |
| --------- | ---------------------------------------------------- |
| `default` | A filled translucent tint that reads on any surface. |
| `outline` | The outline Button's fill and hairline edge.         |
