A toggle group sets related options on one shell, like text alignment or bold, italic, and underline. Pressed items sink into a deeper fill, whether one or several are on.

For actions rather than options, use [`ButtonGroup`](/docs/components/button-group). For a single on/off control, use [`Toggle`](/docs/components/toggle).

## Composition

```text
ToggleGroup
├── ToggleGroupItem
└── ToggleGroupSeparator
```

Give each `ToggleGroupItem` a `value`; the group reports the pressed values as an array.

## Accessibility

### Labels

Give the group an `aria-label` that names the choice ("Text alignment"), and every icon-only item its own.

### Keyboard

Tab moves focus into the group; arrow keys move between items, and Space or Enter presses one. Set `loopFocus={false}` to stop at the ends.

### Selection

Each item exposes its state with `aria-pressed`, and the label darkens when pressed, so the fill is never the only cue. In forced-colors mode the pressed item gets a Highlight border.

## API Reference

The Toggle Group is built on top of [Base UI's Toggle Group](https://base-ui.com/react/components/toggle-group). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Toggle Group documentation](https://base-ui.com/react/components/toggle-group).

### Props

#### ToggleGroup

The shell around the items. Wraps Base UI's `ToggleGroup`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"outline" | "soft" | "ghost"'
  simpleType="string"
  defaultValue='"outline"'
>
  Shell style. `ghost` draws none.
</ApiProp>

<ApiProp
  name="size"
  fullType='"sm" | "default" | "lg"'
  simpleType="string"
  defaultValue='"default"'
>
  Outer height, matching `Button`. Items take it from the group.
</ApiProp>

</ApiPropsList>

### Notes

#### ToggleGroupItem

Wraps [`Toggle`](/docs/components/toggle) and takes its props except `variant` and `size`, which come from the group.

#### ToggleGroupSeparator

A line between items. Wraps [`Separator`](/docs/components/separator); its `orientation` defaults to perpendicular to the group. Arrow keys skip it.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                        | Now                                                                               |
| --------------------------------------------- | --------------------------------------------------------------------------------- |
| `variant="solid"`, a muted track, the default | `variant="outline"` is the default. `variant="soft"` is closest to the old track. |
| `detached` split items into separate toggles  | Removed. Use `variant="ghost"` with `className="gap-1"`.                          |
| `separators` drew lines between every item    | Place a `ToggleGroupSeparator` where you want one.                                |
| `ToggleGroupItem` took `variant` and `size`   | Both come from the group.                                                         |
| Recolored with `--tgl-bg-selected` on items   | Set `--toggle-group-selected-bg` and `--toggle-group-selected-fg` on the group.   |
