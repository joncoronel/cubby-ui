A button group puts related actions on one surface, like a file's share, duplicate, and archive, or an editor's undo and redo. A highlight glides between the buttons as you hover or tab along the row.

When one button stays selected, use [`ToggleGroup`](/docs/components/toggle-group). When the row needs arrow-key navigation, use [`Toolbar`](/docs/components/toolbar).

## Composition

```text
ButtonGroup
├── Button
├── ButtonGroupSeparator
└── ButtonGroupText
```

Leave `variant` unset on the buttons inside; they take the group's style.

## Examples

### Variants

Use `variant` to pick the shell the buttons sit on.

<ComponentPreview component="button-group" example="button-group-variants" />

| Variant    | Description                                                   |
| ---------- | ------------------------------------------------------------- |
| `outline`  | The default. An outline Button's fill and border.             |
| `soft`     | A secondary Button's fill, for editor chrome.                 |
| `elevated` | A raised surface, for toolbars that float.                    |
| `solid`    | The neutral fill, for a primary action and options.           |
| `attached` | No shell; joins buttons to fields. See [Attached](#attached). |

## Accessibility

### Labels

The group renders `role="group"`. Give it an `aria-label` that names the set ("File actions"), and give every icon-only button its own.

### Keyboard

Tab moves through the buttons one at a time. For arrow-key navigation along a long row, use [`Toolbar`](/docs/components/toolbar).

### Highlight

The highlight follows the pointer and keyboard focus and skips disabled buttons. Focus also draws a ring, so the highlight is never the only cue. With reduced motion, it jumps instead of sliding. Browsers without CSS anchor positioning show a hover color on each button instead.

## API Reference

Button Group is a custom component built from plain HTML elements; every prop below is specific to it. Each part also accepts the props of the element it renders.

### Props

#### ButtonGroup

Groups buttons on one surface. Renders a `div` with `role="group"`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"outline" | "soft" | "elevated" | "solid" | "attached"'
  simpleType="string"
  defaultValue='"outline"'
>
  Shell style. `attached` draws no shell and joins its children. A nested group
  inherits its parent's variant.
</ApiProp>

<ApiProp
  name="size"
  fullType='"sm" | "default" | "lg"'
  simpleType="string"
  defaultValue='"default"'
>
  Sets the outer height to Button's `sm`, `default`, or `lg`. Has no effect on
  `attached`.
</ApiProp>

<ApiProp
  name="orientation"
  fullType='"horizontal" | "vertical"'
  simpleType="string"
  defaultValue='"horizontal"'
>
  Lays the buttons out in a row or a column.
</ApiProp>

<ApiProp name="highlight" fullType="boolean" defaultValue="true">
  Glides one shared highlight between buttons. With `false`, each button paints
  its own hover. Has no effect on `attached`.
</ApiProp>

</ApiPropsList>

#### ButtonGroupSeparator

A line between buttons. Wraps [`Separator`](/docs/components/separator).

<ApiPropsList>

<ApiProp
  name="orientation"
  fullType='"horizontal" | "vertical"'
  simpleType="string"
  defaultValue="perpendicular to the group"
>
  Direction of the line: vertical in a row, horizontal in a column.
</ApiProp>

</ApiPropsList>

#### ButtonGroupText

A read-only segment for a label or value. Renders a `div`; pass `render={<label />}` to label an input in an attached group.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                       | Now                                                                                                                                                                |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Installed as `cubby-ui/button-group.tsx`     | Installs into a `cubby-ui/button-group/` folder with `button-group.css`. Import from `@/components/ui/cubby-ui/button-group/button-group` and delete the old file. |
| Children fused into one bordered control     | The default is `outline`, a shell. Pass `variant="attached"` for the old look.                                                                                     |
| `ButtonGroupSeparator` defaulted to vertical | It turns perpendicular to the group, so vertical groups need no `orientation`.                                                                                     |
| Buttons in a group set `variant="outline"`   | Leave `variant` unset in a shell. A set variant marks the button as the main action.                                                                               |
