The slider lets users pick a value, or a range, by dragging a thumb along a track. Use it for volume, brightness, price ranges, and other continuous settings where quick adjustment matters more than typing an exact number.

## Composition

```text
Slider
├── SliderLabel
└── SliderValue
```

`SliderLabel` and `SliderValue` are optional children that render above the track, so a label and value side by side make a header row:

```tsx
<Slider defaultValue={[50]}>
  <div className="flex items-center justify-between">
    <SliderLabel>Volume</SliderLabel>
    <SliderValue />
  </div>
</Slider>
```

For content _below_ the track, render it as a sibling of `Slider` rather than a child (for example, a `<FieldDescription>` inside the enclosing `<Field>`).

### Variants

Use `variant` to change the slider's visual style.

<ComponentPreview component="slider" example="slider-variant" />

| Variant       | Description                                                                                                    |
| ------------- | -------------------------------------------------------------------------------------------------------------- |
| `default`     | A round thumb centered on the track.                                                                           |
| `inset`       | A tall track with a handle that sits inside the fill.                                                          |
| `bar`         | A tall track with a thin bar handle just inside the fill's end, and optional `startLabel` and `endLabel` text. |
| `squareThumb` | A square thumb in place of the round default.                                                                  |

## Accessibility

The slider is operable from the keyboard: focus a thumb, then use the arrow keys to adjust by `step`, `Home`/`End` to jump to the min and max, and `PageUp`/`PageDown` for larger increments.

Give the slider an accessible name when there is no visible `SliderLabel`. For a range slider, use `getAriaLabel` so each thumb gets its own label.

```tsx showLineNumbers
<Slider
  defaultValue={[20, 60]}
  getAriaLabel={(index) => (index === 0 ? "Minimum price" : "Maximum price")}
/>
```

## API Reference

The Slider is built on top of [Base UI's Slider](https://base-ui.com/react/components/slider). All Base UI props are supported except `thumbAlignment`, which the variant sets. The documentation below only covers custom props and the props our implementation handles.

For the complete Base UI API, see the [Base UI Slider documentation](https://base-ui.com/react/components/slider).

### Props

#### Slider

Track, fill, marks, and thumbs for one value or a range. Composes Base UI's `Slider.Root`, `Slider.Control`, `Slider.Track`, `Slider.Indicator`, and `Slider.Thumb`. Props are forwarded to `Slider.Root`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "inset" | "bar" | "squareThumb"'
  simpleType="string"
  defaultValue='"default"'
>
  Sets the visual style. `inset` is a tall track with the handle inside the
  fill; `bar` is a tall track with a thin bar handle and room for labels;
  `squareThumb` swaps the round thumb for a square one.
</ApiProp>

<ApiProp
  name="color"
  fullType='"neutral" | "primary"'
  simpleType="string"
  defaultValue='"neutral"'
>
  Sets the fill of the selected range. `neutral` is the emphasis grey shared by
  selection controls; `primary` is the brand fill.
</ApiProp>

<ApiProp name="showSteps" fullType='boolean | "hover"' defaultValue="false">
  Marks each step on the track. `"hover"` shows the marks only while the slider
  is hovered, focused, or dragged. The `inset` variant marks every step, with
  lighter marks on the fill; the others skip the ends, where the thumb sits.
</ApiProp>

<ApiProp name="markStep" fullType="number">
  The spacing between marks, in value units. Defaults to `step`. Set it wider
  than `step` to mark the scale without snapping to the marks.
</ApiProp>

<ApiProp name="startLabel" fullType="React.ReactNode">
  Content inside the track at its start, such as "Low" or a setting name. Turns
  the fill's foreground color where the fill covers it. `bar` variant only.
</ApiProp>

<ApiProp name="endLabel" fullType="React.ReactNode">
  Content inside the track at its end, such as "High" or a `SliderValue`. Turns
  the fill's foreground color where the fill covers it. `bar` variant only.
</ApiProp>

<ApiProp name="getAriaLabel" fullType="((index: number) => string) | null">
  Returns an accessible name for each thumb. Use it when there's no visible
  label, or in a range so each thumb gets its own name.
</ApiProp>

<ApiProp name="min" fullType="number" defaultValue="0">
  The lowest value.
</ApiProp>

<ApiProp name="max" fullType="number" defaultValue="100">
  The highest value.
</ApiProp>

</ApiPropsList>

#### SliderValue

The current value as text, formatted by the slider's `format` prop. Wraps Base UI's `Slider.Value`.

#### SliderLabel

The slider's visible label. Wraps Base UI's `Slider.Label`.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                              | Now                                                                              |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| Range and thumb in the primary blue | A `color` prop, `neutral` by default. Pass `color="primary"` for the brand fill. |
| `variant="contained"`               | Removed. Use `variant="inset"`, a tall track with the handle inside the fill.    |
