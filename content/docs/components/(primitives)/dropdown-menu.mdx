A menu of actions or links that opens from a trigger button. Use it for row actions, a "more options" overflow button, account menus, or any compact list of commands. For a horizontal bar of menus (File, Edit, View), use [Menubar](/docs/components/menubar) instead.

## Composition

```text
DropdownMenuFilter         (optional, enables filtering)
DropdownMenu
├── DropdownMenuTrigger
└── DropdownMenuContent
    ├── DropdownMenuInput      (with filtering)
    ├── DropdownMenuEmpty      (with filtering)
    ├── DropdownMenuList       (with filtering, wraps the items)
    ├── DropdownMenuGroup
    │   ├── DropdownMenuGroupLabel
    │   └── DropdownMenuItem
    ├── DropdownMenuLinkItem
    ├── DropdownMenuLabel
    ├── DropdownMenuCheckboxItem
    ├── DropdownMenuRadioGroup
    │   └── DropdownMenuRadioItem
    ├── DropdownMenuShortcut   (inside an item)
    ├── DropdownMenuSeparator
    └── DropdownMenuSub
        ├── DropdownMenuSubTrigger
        └── DropdownMenuSubContent
```

`DropdownMenuContent` composes the portal, positioner, and popup internally, so you place items directly inside it.

To control positioning or the popup yourself, compose the parts instead: `DropdownMenuPortal` › `DropdownMenuPositioner` › `DropdownMenuPopup`. `DropdownMenuContent` also wraps its items in a `DropdownMenuViewport`, which crossfades content when detached triggers swap the menu. Leave the viewport out of menus that never swap content: without it Base UI positions the menu with `transform`, which keeps movement on the compositor.

### Aligning Items With and Without Icons

Menu items lay their icon out inline, so an item with no icon starts its label further left than its neighbours. Add `inset` to the icon-less items to give them the same left padding an icon would have occupied, and every label lines up on one edge.

`inset` is available on `DropdownMenuItem`, `DropdownMenuLinkItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioItem`, `DropdownMenuLabel`, `DropdownMenuGroupLabel`, and `DropdownMenuSubTrigger`. Only reach for it in menus that actually mix the two kinds of item.

### With Filter

Wrap `DropdownMenu` in `DropdownMenuFilter`, then put a `DropdownMenuInput` above a `DropdownMenuList` to filter items as you type. Wrap a `DropdownMenuSub` in its own `DropdownMenuFilter` to make the submenu searchable too.

<ComponentPreview
  component="dropdown-menu"
  example="dropdown-menu-with-filter"
/>

Set a width on `DropdownMenuContent` so the menu doesn't narrow as long items filter out. Items match on their text, ignoring case, accents, and punctuation. Give an item a `label` when its text isn't what people would type, or pass a `filter` function (such as `startsWith` from `useDropdownMenuFilter()`) to change how items match. Filtering is a preview API in Base UI and may change in a minor release.

## API Reference

The DropdownMenu component is built on top of [Base UI's Menu](https://base-ui.com/react/components/menu). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Menu documentation](https://base-ui.com/react/components/menu).

One exception: `DropdownMenuSub` renders `Menu.SubmenuRoot`, which does not accept `modal`, `openOnHover`, `handle`, `triggerId` or `defaultTriggerId`. Those belong on the root `DropdownMenu`.

### Props

#### DropdownMenuContent

Dropdown container with positioning and animations. Composes `DropdownMenuPortal`, `DropdownMenuPositioner`, `DropdownMenuPopup`, and `DropdownMenuViewport`. Props are forwarded to `DropdownMenuPopup`.

<ApiPropsList>

<ApiProp
  name="side"
  fullType='"top" | "right" | "bottom" | "left"'
  simpleType="string"
  defaultValue='"bottom"'
>
  Which side of the trigger to position the menu. This prop is flattened from
  the Positioner component for convenience.
</ApiProp>

<ApiProp
  name="align"
  fullType='"start" | "center" | "end"'
  simpleType="string"
  defaultValue='"center"'
>
  How to align the menu relative to the trigger. This prop is flattened from the
  Positioner component for convenience.
</ApiProp>

<ApiProp name="sideOffset" fullType="number" defaultValue="4">
  Distance in pixels between trigger and menu. This prop is flattened from the
  Positioner component for convenience.
</ApiProp>

<ApiProp name="level" fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8" defaultValue="3">
  Surface elevation level. See the [Surfaces](/docs/getting-started/surfaces)
  docs. Bump higher when the menu lives inside an already-elevated parent (e.g.,
  `level={7}` inside a Dialog).
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  defaultValue="3"
>
  Shadow weight. Controls drop-shadow intensity independently of substrate
  color.
</ApiProp>

<ApiProp name="positionerClassName" fullType="string">
  Classes for the positioner, the element Base UI moves into place. Merged last,
  so it overrides the defaults, such as `duration-100` for a faster glide.
  Custom prop not available in Base UI.
</ApiProp>

</ApiPropsList>

#### DropdownMenuPopup

The styled menu surface, with its entrance and exit. Accepts `level` and `shadowLevel` like `DropdownMenuContent`; other props go to `Menu.Popup`.

#### DropdownMenuViewport

Crossfades content when detached triggers swap what the menu shows, with `p-1` around the items. Props go to `Menu.Viewport`.

#### DropdownMenuItem

Individual menu item. Wraps Base UI's `Menu.Item`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Indent the label by the width an icon would occupy, so icon-less items line up
  with icon items in the same menu. See [Aligning Items With and Without
  Icons](#aligning-items-with-and-without-icons).
</ApiProp>

<ApiProp
  name="variant"
  fullType='"default" | "destructive"'
  simpleType="string"
  defaultValue='"default"'
>
  Visual style variant. Use `"destructive"` for dangerous actions like delete or
  remove operations.
</ApiProp>

</ApiPropsList>

#### DropdownMenuLinkItem

Menu item that renders as an anchor (`<a>`) for navigation links. Wraps Base UI's `Menu.LinkItem`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Indent the label by the width an icon would occupy, so icon-less items line up
  with icon items in the same menu. See [Aligning Items With and Without
  Icons](#aligning-items-with-and-without-icons).
</ApiProp>

</ApiPropsList>

#### DropdownMenuCheckboxItem

Toggleable menu item. Wraps Base UI's `Menu.CheckboxItem`. The indicator sits in a reserved column on the right, matching [Select](/docs/components/select).

<ApiPropsList>

<ApiProp
  name="indicator"
  fullType='"check" | "switch"'
  simpleType="string"
  defaultValue='"check"'
>
  Indicator style. `"switch"` renders a decorative switch in place of the
  checkmark. It is purely visual: the item keeps the `menuitemcheckbox` role,
  the same props, and the same behavior.
</ApiProp>

<ApiProp
  name="switchColor"
  fullType='"primary" | "neutral"'
  simpleType="string"
  defaultValue='"primary"'
>
  Checked track colour, when `indicator="switch"`. Forwarded to
  [Switch](/docs/components/switch).
</ApiProp>

<ApiProp
  name="switchShape"
  fullType='"circle" | "pill" | "squircle"'
  simpleType="string"
  defaultValue='"circle"'
>
  Thumb silhouette, when `indicator="switch"`. Forwarded to
  [Switch](/docs/components/switch).
</ApiProp>

<ApiProp
  name="switchSize"
  fullType='"xs" | "sm" | "default"'
  simpleType="string"
  defaultValue='"xs"'
>
  Thumb size, when `indicator="switch"`. The default matches the row's text.
</ApiProp>

<ApiProp
  name="switchMotion"
  fullType='"default" | "stretch"'
  simpleType="string"
  defaultValue='"default"'
>
  What the thumb does while toggling, when `indicator="switch"`. `"stretch"`
  sends the leading edge first, so the thumb spans the track mid-toggle.
</ApiProp>

<ApiProp name="inset" fullType="boolean">
  Indent the label by the width an icon would occupy, so icon-less items line up
  with icon items in the same menu. See [Aligning Items With and Without
  Icons](#aligning-items-with-and-without-icons).
</ApiProp>

</ApiPropsList>

#### DropdownMenuRadioItem

Mutually exclusive menu item. Wraps Base UI's `Menu.RadioItem`. Uses the same right-aligned checkmark as `DropdownMenuCheckboxItem`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">

  with icon items in the same menu. See [Aligning Items With and Without
  Icons](#aligning-items-with-and-without-icons).
</ApiProp>

</ApiPropsList>

#### DropdownMenuLabel

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">

</ApiProp>

</ApiPropsList>

#### DropdownMenuGroupLabel

Label for a menu group. Wraps Base UI's `Menu.GroupLabel`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Indent the label by the width an icon would occupy, so icon-less items line up
  with icon items in the same menu. See [Aligning Items With and Without

</ApiProp>

</ApiPropsList>

#### DropdownMenuSubTrigger

Item that opens a submenu on hover. Wraps Base UI's `Menu.SubmenuTrigger`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Indent the label by the width an icon would occupy, so icon-less items line up
  with icon items in the same menu. See [Aligning Items With and Without
  Icons](#aligning-items-with-and-without-icons).
</ApiProp>

<ApiProp name="delay" fullType="number" defaultValue="0">
  Delay in milliseconds before opening the submenu on hover.
</ApiProp>

<ApiProp name="closeDelay" fullType="number" defaultValue="0">
  Delay in milliseconds before closing the submenu when hovering away.
</ApiProp>

</ApiPropsList>

#### DropdownMenuSubContent

Submenu container with positioning. Composes `Menu.Portal`, `Menu.Positioner`, and `Menu.Popup`. Props are forwarded to `Menu.Popup`.

<ApiPropsList>

<ApiProp name="sideOffset" fullType="number" defaultValue="8">
  Distance in pixels for positioning the submenu relative to its trigger. Base
  UI defaults to `0`, which overlaps the parent popup's padding; `8` leaves a
  visible gap.
</ApiProp>

<ApiProp
  name="align"
  fullType='"start" | "center" | "end"'
  simpleType="string"
  defaultValue='"start"'
>
  How to align the submenu relative to its trigger.
</ApiProp>

<ApiProp name="alignOffset" fullType="number" defaultValue="-5">
  Vertical offset to align the first submenu item with its trigger. Defaults to
  `-5` when `align` is not `"center"`.
</ApiProp>

<ApiProp name="level" fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8" defaultValue="5">
  Surface elevation level. Submenus default to `5` so they pop above the parent
  dropdown at level 3.
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  defaultValue="3"
>
  Shadow weight. Kept at `3` (same as parent dropdown), since submenus are still
  small popups.
</ApiProp>

<ApiProp name="positionerClassName" fullType="string">
  Classes for the positioner, the element Base UI moves into place. Merged last,
  so it overrides the defaults, such as `duration-100` for a faster glide.
  Custom prop not available in Base UI.
</ApiProp>

</ApiPropsList>

#### DropdownMenuFilter

Enables filtering for the `DropdownMenu` or `DropdownMenuSub` it wraps. Wraps Base UI's `Menu.FilterProvider` and renders no element.

<ApiPropsList>

<ApiProp
  name="autoHighlight"
  fullType="boolean | 'always'"
  simpleType="boolean | string"
  defaultValue="true"
>
  Highlight the first matching item while the query has text, so Enter runs it.
  Base UI defaults to `false`.
</ApiProp>

</ApiPropsList>

#### DropdownMenuInput

The search field: an icon, Base UI's `Menu.Input`, and a clear button, drawn like the menu's rows. It sits above `DropdownMenuList`, which scrolls on its own with the same edge fade as Combobox's list. Props are forwarded to `Menu.Input`.

<ApiPropsList>

<ApiProp name="aria-label" fullType="string" defaultValue='"Search"'>
  Accessible name for the field, since the placeholder doesn't count as one.
  Pass something specific, like `"Search actions"`.
</ApiProp>

<ApiProp name="showClear" fullType="boolean" defaultValue="true">
  Show a `DropdownMenuClear` button while the query has text. Custom prop not
  available in Base UI.
</ApiProp>

<ApiProp name="inputClassName" fullType="string">
  Class applied to the inner `<input>`. `className` styles the field.
  Custom prop not available in Base UI.
</ApiProp>

</ApiPropsList>
