A preview card shows what a link points to, like a profile, an article, or a definition, when the pointer rests on the link or it gets focus. Use it to help someone decide whether to follow the link. For a short label on an icon button, use [`Tooltip`](/docs/components/tooltip). For anything with controls inside, use [`Popover`](/docs/components/popover).

## Composition

```text
PreviewCard
├── PreviewCardTrigger
└── PreviewCardContent
    ├── PreviewCardMedia
    ├── PreviewCardTitle
    └── PreviewCardDescription
```

`PreviewCardContent` renders the portal, positioner, popup, and viewport. The media, title, and description parts are optional; put any markup you like inside the content.

`PreviewCardTrigger` renders an `<a>`. Give it an `href` so the link still works for anyone who clicks, taps, or never sees the card.

## Examples

### Link Preview

Use `PreviewCardMedia` to run an image edge to edge along the top, in the 1.91:1 ratio of a page's `og:image`.

<ComponentPreview component="preview-card" example="preview-card-link" />

### Shared Card

Pass one handle from `createPreviewCardHandle` to a `PreviewCard` and any number of triggers, and the card glides between them, rendering each trigger's `payload`.

<ComponentPreview component="preview-card" example="preview-card-group" />

```tsx
const handle = createPreviewCardHandle<Person>();

function Contributors({ people }: { people: Person[] }) {
  return (
    <>
      {people.map((person) => (
        <PreviewCardTrigger
          key={person.id}
          handle={handle}
          payload={person}
          href={person.url}
        >
          {person.name}
        </PreviewCardTrigger>
      ))}
      <PreviewCard handle={handle}>
        {({ payload }) => (
          <PreviewCardContent>{payload?.name}</PreviewCardContent>
        )}
      </PreviewCard>
    </>
  );
}
```

The triggers can sit anywhere in the tree, and a long list mounts one card instead of one per row.

## Accessibility

### Keep essential information out of the card

Touch screens have no hover, so tapping the trigger follows the link and the card never opens. Anything a reader needs belongs on the page itself.

### Keyboard and motion

Focusing the trigger opens the card after the same delay as hover, without animation, and Escape closes it. With reduced motion on, the card fades in and out and switching triggers crossfades the content, with no scale, blur, glide, or nudge.

## API Reference

The PreviewCard component is built on top of [Base UI's PreviewCard](https://base-ui.com/react/components/preview-card). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI PreviewCard documentation](https://base-ui.com/react/components/preview-card).

### Utilities

#### createPreviewCardHandle

Creates a handle that connects one `PreviewCard` to triggers anywhere in the tree. Pass a type argument to type each trigger's `payload`. The handle also has `open(triggerId)`, `close()`, and `isOpen` for driving the card from your own code.

### Props

#### PreviewCardTrigger

Link that opens the card. Wraps Base UI's `PreviewCard.Trigger`.

<ApiPropsList>

<ApiProp name="delay" fullType="number" simpleType="number" defaultValue="400">
  Milliseconds the pointer rests on the trigger before the card opens. Base UI
  defaults to `600`.
</ApiProp>

<ApiProp
  name="closeDelay"
  fullType="number"
  simpleType="number"
  defaultValue="200"
>
  Milliseconds after the pointer leaves before the card closes. Long enough to
  reach a neighboring trigger on the same handle. Base UI defaults to `300`.
</ApiProp>

</ApiPropsList>

#### PreviewCardContent

The card itself. Composes `PreviewCard.Portal`, `PreviewCard.Positioner`, `PreviewCard.Popup`, and `PreviewCard.Viewport`, and optionally `PreviewCard.Arrow`. Props are forwarded to `PreviewCard.Popup`.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                                      | Now                                                                                                             |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Opened and closed instantly (`delay={0}`, `closeDelay={0}`) | 400ms open and 200ms close delays. Pass `delay={0}` and `closeDelay={0}` on the trigger to keep the old timing. |
| `arrow` defaulted to `true`                                 | `arrow` defaults to `false`. Pass `arrow` to keep it.                                                           |
| Padding on the card, removed with `className="p-0"`         | Padding on the inner viewport. Use `viewportClassName="[--viewport-padding:0px]"`.                              |
| Fixed `w-64` card                                           | Sizes to its content up to 20rem. Set a width with `className="w-64"`, and `max-w-*` to go past 20rem.          |
