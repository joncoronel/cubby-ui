An OTP field splits a one-time passcode across individual character slots, with paste and auto-advance handled for you. Use it for two-factor codes, email verification, or recovery codes.

### Outline Variant

Use `variant="outline"` on each `OTPFieldInput` to match the outline Button: a card fill with a hairline border in light mode, a recessed fill with a faint ring in dark mode. The `default` tint already reads on the page, Cards, Dialogs, and popovers, so no field needs a per-surface variant.

| Variant   | Description                                   |
| --------- | --------------------------------------------- |
| `default` | A translucent tint that reads on any surface. |
| `outline` | The outline Button's fill and hairline edge.  |

## API Reference

The OTP Field is built on top of [Base UI's OTP Field](https://base-ui.com/react/components/otp-field). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI OTP Field documentation](https://base-ui.com/react/components/otp-field).

### Props

#### OTPField

Groups all OTP field parts and manages their state. Wraps Base UI's `OTPField.Root`. Renders a `<div>`, plus a single focus ring that slides to whichever slot has focus.

No custom props. To change the slot and ring rounding together, set `--otp-field-radius` on it (e.g. `className="[--otp-field-radius:9999px]"`). All Base UI Root props are passed through, including `length`, `value`, `onValueChange`, `validationType`, `mask`, `normalizeValue`, and `onValueInvalid`.

#### OTPFieldInput

Individual character input slot. Wraps Base UI's `OTPField.Input`. Renders an `<input>` inside a slot `<span>`; `className` (a string, not Base UI's state function) and `style` go to the slot. The input's own text is hidden and each character rolls in through [Text Morph](/docs/components/text-morph); the caret shows in an empty slot and hides once it's filled. The `render` prop isn't supported.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "outline"'
  simpleType="string"
  defaultValue='"default"'
>
  Sets the slot's fill. `default` is a translucent tint that reads on any
  surface; `outline` uses the outline Button's fill and hairline edge.
</ApiProp>

</ApiPropsList>

#### OTPFieldSeparator

Visual separator between input groups. Wraps Base UI's `Separator`. Renders a `<div>`.

<ApiPropsList>

<ApiProp name="children" fullType="ReactNode" simpleType="node">
  Content to render inside the separator. Defaults to a horizontal dash icon
  when no children are provided.
</ApiProp>

</ApiPropsList>

#### OTPFieldGroup

Layout wrapper for grouping inputs together. Not a Base UI component; renders a plain `<div>` with `display: flex` and `gap`.

### Hooks

#### useInvalidFeedback

```ts
function useInvalidFeedback(
  options?: UseInvalidFeedbackOptions,
): UseInvalidFeedbackReturn;
```

Manages shake animation and screen reader feedback for invalid OTP input. Bundled with the component, installed automatically when you install `otp-field`.

Wire its handlers and `className` to `OTPField`. The focused slot and the focus ring shake together:

```tsx
import { useInvalidFeedback } from "@/components/ui/cubby-ui/otp-field/hooks/use-invalid-feedback";

const invalidFeedback = useInvalidFeedback();

<OTPField
  length={6}
  validationType="none"
  normalizeValue={myCustomNormalizer}
  className={invalidFeedback.className}
  onValueChange={invalidFeedback.handleValueChange}
  onValueInvalid={invalidFeedback.handleValueInvalid}
>
  {Array.from({ length: 6 }, (_, index) => (
    <OTPFieldInput key={index} />
  ))}
</OTPField>
<span aria-live="polite" className="sr-only">
  {invalidFeedback.statusMessage}
</span>
```

##### Options

<ApiPropsList>

<ApiProp name="duration" fullType="number" defaultValue="400">
  Duration in milliseconds before the shake animation clears.
</ApiProp>

</ApiPropsList>

##### Returns

| Property             | Type                      | Description                                                                         |
| -------------------- | ------------------------- | ----------------------------------------------------------------------------------- |
| `handleValueChange`  | `() => void`              | Clears invalid feedback. Wire to `OTPField`'s `onValueChange`.                      |
| `handleValueInvalid` | `(value: string) => void` | Triggers shake animation and status message. Wire to `OTPField`'s `onValueInvalid`. |
| `className`          | `string \| undefined`     | Shake className while feedback is active, or `undefined`. Pass to `OTPField`.       |
| `statusMessage`      | `string`                  | Screen reader announcement. Render inside an `aria-live="polite"` region.           |

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                               | Now                                                                     |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| `variant="elevated"` for fields on Cards and Dialogs | Removed. The default tint works on any surface, so drop the prop.       |
| One filled style                                     | `variant="outline"` adds a bordered style, matching the outline Button. |
