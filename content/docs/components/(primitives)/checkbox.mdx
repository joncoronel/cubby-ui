import { Checkbox } from "@/registry/default/checkbox/checkbox";

The checkbox toggles a single on/off value, with checked, unchecked, and indeterminate states. Use it for individual settings, consent agreements, or one item in a list; for a set of related options sharing one value, reach for [`CheckboxGroup`](/docs/components/checkbox-group).

<ComponentPreview component="checkbox" example="checkbox-disabled-state" />

### Tone

A checked box fills with the neutral emphasis grey by default, the same grey as every other selection control. Pass `tone="primary"` to fill it with the brand color instead.

<ComponentPreview component="checkbox" example="checkbox-tone" />

### Elevated Variant

Use `variant="elevated"` on a Card, Dialog, or popover surface, where the lighter `default` tint would fade into its parent. See the [Surfaces](/docs/getting-started/surfaces) docs.

<ComponentPreview component="checkbox" example="checkbox-elevated" />

| Value      | Description                                                           |
| ---------- | --------------------------------------------------------------------- |
| `default`  | The `bg-input` tint, for standard page backgrounds.                   |
| `elevated` | The stronger `bg-input-elevated` tint, for Card, Dialog, or popovers. |

## API Reference

The Checkbox component is built on top of [Base UI's Checkbox](https://base-ui.com/react/components/checkbox). All Base UI props are supported. The documentation below only covers custom props specific to our implementation.

### Props

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "elevated"'
  simpleType="string"
  defaultValue='"default"'
>
  Surface appearance. `default` uses the `bg-input` tint. `elevated` uses the
  stronger `bg-input-elevated` tint for use inside Card, Dialog, or popover
  surfaces. See the [Surfaces](/docs/getting-started/surfaces) docs.
</ApiProp>

<ApiProp
  name="tone"
  fullType='"neutral" | "primary"'
  simpleType="string"
  defaultValue='"neutral"'
>
  Fill color when checked or indeterminate. `neutral` uses the emphasis grey
  shared by selection controls. `primary` uses the brand fill.
</ApiProp>

</ApiPropsList>
