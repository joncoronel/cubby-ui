A preview card shows a richer look at what a link points to, like a profile, an article, or a definition, when the pointer rests on it or it receives focus. Use it for content that helps someone decide whether to follow the link. For a short label on an icon button, use [`Tooltip`](/docs/components/tooltip). For anything with controls inside, use [`Popover`](/docs/components/popover).

## Composition

```text
PreviewCard
├── PreviewCardTrigger
└── PreviewCardContent
    ├── PreviewCardMedia
    ├── PreviewCardTitle
    └── PreviewCardDescription
```

`PreviewCardContent` composes the portal, positioner, popup, and viewport for you. The media, title, and description parts are optional. Put any markup you like inside the content.

`PreviewCardTrigger` renders an `<a>`. Give it an `href` so the link still works for someone who clicks, taps, or never sees the card.

## Examples

### Link Preview

Use `PreviewCardMedia` for an image along the top edge. It bleeds past the card padding, follows the card's corners, and defaults to the 1.91:1 Open Graph ratio, so a page's `og:image` fits without cropping.

<ComponentPreview component="preview-card" example="preview-card-link" />

### Shared Card

Create a handle with `createPreviewCardHandle` and pass it to one `PreviewCard` and to any number of triggers. Each trigger sends its own `payload`, and the card renders it with a function child. Moving from one trigger to the next glides the card across and slides the new content in from the direction you moved.

<ComponentPreview component="preview-card" example="preview-card-group" />

```tsx
const handle = createPreviewCardHandle<Person>();

{
  people.map((person) => (
    <PreviewCardTrigger
      key={person.id}
      handle={handle}
      payload={person}
      href={person.url}
    >
      {person.name}
    </PreviewCardTrigger>
  ));
}

<PreviewCard handle={handle}>
  {({ payload }) => <PreviewCardContent>{payload?.name}</PreviewCardContent>}
</PreviewCard>;
```

The triggers can live anywhere in the tree. One card serving a long list also mounts far less than a card per row.

### Arrow

Set `arrow` to point the card at its trigger. It tracks the trigger as the card flips or shifts near the edge of the screen.

### Wrapping Text

When the link wraps across lines, the card anchors to the line the pointer is on instead of the whole phrase. It works with no extra props.

## Behavior

- **Timing.** The card opens after the pointer rests on the trigger for 400ms and closes 200ms after it leaves. Set `delay` and `closeDelay` on the trigger to change them.
- **Reaching the card.** The pointer can travel from the trigger into the card without it closing, so links inside the card stay usable.
- **Keyboard.** Focusing the trigger opens the card after the same delay, without the entrance animation. Escape closes it.
- **Touch.** Preview cards open on hover and focus, which touch screens don't have. Tapping the trigger follows the link, so never put the only copy of important information in the card.
- **Reduced motion.** With reduced motion on, the card appears and moves without animating.

## API Reference

The PreviewCard component is built on top of [Base UI's PreviewCard](https://base-ui.com/react/components/preview-card). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI PreviewCard documentation](https://base-ui.com/react/components/preview-card).

#### createPreviewCardHandle

Returns a handle that connects triggers to a `PreviewCard` anywhere in the tree. Pass a type argument to type each trigger's `payload`. The handle also has `open(triggerId)`, `close()`, and `isOpen` for opening and closing the card from your own code.

### Modified Defaults

Our implementation changes the following Base UI prop defaults:

- **PreviewCardTrigger**: `delay` defaults to `400` (Base UI defaults to `600`)
- **PreviewCardTrigger**: `closeDelay` defaults to `200` (Base UI defaults to `300`)
- **PreviewCardContent**: `sideOffset` defaults to `8` (Base UI defaults to `0`)
- **PreviewCardContent**: `collisionPadding` defaults to `10` (Base UI defaults to `5`)
