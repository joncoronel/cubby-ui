The date picker is a field that opens a calendar popover for choosing a single date. Use it for due dates, birthdays, and any form field that needs one date. It formats the date for the reader's locale, can sit beside one-click presets, and submits with a plain form.

To select a start and end date together, use [`DateRangePicker`](/docs/components/date-range-picker) instead.

## Examples

### Controlled

Pass `value` and `onValueChange` to manage the date yourself. An empty field is `null`. Add `clearable` for a button that empties it.

<ComponentPreview component="date-picker" example="date-picker-controlled" />

### Typing a Date

Set `editable` to make the field a text input, with the calendar on the button beside it. It reads what people actually type: "today", "tomorrow", "next fri", "in 2 weeks", "mar 14", "14 March 2027", "3/14" (in the locale's day and month order), or "2026-03-14". A hint on the right shows how the text will be read before anything changes; `Enter` or leaving the field commits it, and `Escape` undoes the edit.

<ComponentPreview component="date-picker" example="date-picker-editable" />

### Presets

Pass `presets` for one-click shortcuts beside the calendar. Give each a function rather than a fixed date so relative presets like "Tomorrow" are worked out when the picker opens.

### Min and Max

`minDate` and `maxDate` block days outside the window and stop the calendar from navigating past it. Use `disabledDates` for anything else, such as weekends.

## Accessibility

The trigger is a button that opens the calendar in a popover and moves focus into it. Inside, use the arrow keys to move between days, `PageUp` and `PageDown` to change months, and `Enter` or `Space` to pick. Picking a date closes the popover and returns focus to the trigger; `Escape` closes it without a change. The clear button is a separate control after the trigger, labelled "Clear date".

With `editable`, the field is a text input (label it with `id` and a `<label>`, or `aria-label`), and the calendar opens from a "Choose date" button beside it or with `ArrowDown` in the input. The hint is a polite live region, so how the text was read ("Fri, Oct 9, 2026", "Unavailable") is announced, and text that can't be read marks the input `aria-invalid` when committed.

## API Reference

The DatePicker composes [`Calendar`](/docs/components/calendar) inside a [`Popover`](/docs/components/popover), with a trigger styled like an [`Input`](/docs/components/input). Props not listed below (`id`, `aria-*`, event handlers) go to the trigger button.

#### DatePicker

  Fires when a date is picked or cleared.
</ApiProp>

<ApiProp name="open" fullType="boolean">

</ApiProp>

<ApiProp
  name="onOpenChange"

  simpleType="function"

  Fires when the popover opens or closes.

<ApiProp name="placeholder" fullType="string" defaultValue='"Pick a date"'>
  Text shown on the trigger when no date is selected.
</ApiProp>

<ApiProp name="format" fullType="(date: Date) => string" simpleType="function">
  Writes the date on the trigger. Defaults to the locale's medium date, such as
  "Oct 1, 2026".
</ApiProp>

<ApiProp name="editable" fullType="boolean" defaultValue="false">
  Makes the field a text input that reads typed dates, with the calendar on a
  button beside it. Rest props go to the input instead of the trigger.
</ApiProp>

<ApiProp name="clearable" fullType="boolean" defaultValue="false">
  Shows a button that clears the date.
</ApiProp>

<ApiProp name="minDate" fullType="Date">
  Earliest selectable date. Also stops navigation before its month.
</ApiProp>

<ApiProp name="maxDate" fullType="Date">
  Latest selectable date. Also stops navigation after its month.
</ApiProp>

<ApiProp name="disabledDates" fullType="Matcher | Matcher[]">
  Extra dates to block, as DayPicker matchers.
</ApiProp>

<ApiProp
  name="presets"

  One-click shortcuts shown beside the calendar. Picking one commits it and

<ApiProp name="name" fullType="string">
  Submits the date as `YYYY-MM-DD` under this name in a form.
</ApiProp>

<ApiProp

<ApiProp name="size" fullType='"default" | "sm"' defaultValue='"default"'>
  Trigger height, matching `Input`.
</ApiProp>

<ApiProp name="disabled" fullType="boolean" defaultValue="false">
  Prevents the popover from opening.

<ApiProp name="labels" fullType="Partial<DatePickerLabels>" simpleType="object">

<ApiProp name="className" fullType="string">
