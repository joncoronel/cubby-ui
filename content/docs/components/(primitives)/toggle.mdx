A toggle is a two-state button that stays pressed when on. Use it for a single on/off control like bold, mute, or pin. For a set of mutually exclusive or multi-select toggles, use [`Toggle Group`](/docs/components/toggle-group); for a labeled settings switch, use [`Switch`](/docs/components/switch).

<ComponentPreview component="toggle" example="toggle-outline-variant" />

| Variant   | Description                                                    |
| --------- | -------------------------------------------------------------- |
| `ghost`   | The default. No fill when off, a neutral fill when on.         |
| `soft`    | A secondary Button's fill when off, a deeper one when on.      |
| `outline` | An outline Button's fill and border, a secondary fill when on. |

### Custom Colors

The toggle paints its fill from CSS variables, one per state:

| Variable            | State                                   |
| ------------------- | --------------------------------------- |
| `--tgl-bg`          | Off.                                    |
| `--tgl-bg-hover`    | Off and hovered.                        |
| `--tgl-bg-active`   | Off and held down. Falls back to hover. |
| `--tgl-bg-selected` | On.                                     |
| `--tgl-border`      | Border color, in every state.           |

Each variant sets them and the toggle picks one per state, so you recolor
the fill by overriding them, with no `hover:` or `data-pressed:` prefixes.
Override them rather than adding `bg-*` to the root: a root `bg-*` paints
behind the fill layer, where opaque variants hide it. Set the label color with
a state-prefixed text class:

```tsx showLineNumbers
<Toggle className="[--tgl-bg-selected:var(--color-violet-600)] data-pressed:text-white">
  <BoldIcon />
</Toggle>
```

Custom properties can't take Tailwind's `/10` opacity shorthand; build a
translucent tint with `color-mix`:

```tsx showLineNumbers
<Toggle className="[--tgl-bg-selected:color-mix(in_oklab,var(--primary)_10%,transparent)]">
  <BoldIcon />
</Toggle>
```

Any variable you don't override keeps the variant's color for that state.

The border lives on the toggle's paint pseudo-element, so `before:` classes
restyle it, for example `before:border-dashed` or `before:border-2`. Only
`outline` sets a visible `--tgl-border`, so on the other variants pair those
classes with a color: `[--tgl-border:var(--border)] before:border-dashed`.

## Accessibility

### Labels

Give an icon-only toggle an `aria-label` that names what it controls, since it has no text for a screen reader to announce.

```tsx showLineNumbers
<Toggle aria-label="Toggle bold">
  <BoldIcon />
</Toggle>
```

## API Reference

The Toggle component is built on top of [Base UI's Toggle](https://base-ui.com/react/components/toggle). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before            | Now                                                      |
| ----------------- | -------------------------------------------------------- |
| `variant="solid"` | `variant="soft"`, a secondary fill that deepens when on. |
| Pressed at 0.97   | Pressed at 0.98, as on `Button`.                         |
