A meter shows a measurement within a known range, like disk usage, battery level, or a score. Give it thresholds and it colors itself by whether the reading is good, borderline, or critical. For the changing completion of a task, use [`Progress`](/docs/components/progress) instead.

## Composition

```text
MeterRoot
├── MeterLabel
├── MeterValue
└── MeterTrack
    └── MeterIndicator
```

`MeterRoot` lays its children out on a grid: the label and value share the first row, and the track (plus anything else you add) spans the full width below.

## Examples

### Sizes

Use `size` to set the track thickness.

<ComponentPreview component="meter" example="meter-sizes" />

| Value | Description                         |
| ----- | ----------------------------------- |
| `sm`  | 4px track for dense lists and rows. |
| `md`  | The default 6px track.              |
| `lg`  | 10px track for a focal reading.     |

### Thresholds

`low`, `high`, and `optimum` work like the native [`<meter>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meter) element. `low` and `high` split the range into three regions, and `optimum` says which region is ideal. A value in that region is optimum (green), the next region over is suboptimum (amber), and the far region is critical (red). A small notch marks each threshold on the track.

Color alone isn't announced, so `getAriaValueText` receives the status as a third argument. Use it to put the status into what screen readers hear.

<ComponentPreview component="meter" example="meter-thresholds" />

| Reading          | Thresholds                              |
| ---------------- | --------------------------------------- |
| Lower is better  | `optimum` below `low`, like disk usage. |
| Higher is better | `optimum` above `high`, like battery.   |
| Middle is best   | `optimum` between them, like humidity.  |

### Live Readings

The indicator eases between values and crossfades its color as a reading crosses a threshold.

## API Reference

The Meter component is built on top of [Base UI's Meter](https://base-ui.com/react/components/meter). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Meter documentation](https://base-ui.com/react/components/meter).

### Custom Props

#### MeterRoot

<ApiPropsList>

<ApiProp
  name="size"
  fullType='"sm" | "md" | "lg"'
  simpleType="string"
  defaultValue='"md"'
>
  Thickness of the track.
</ApiProp>

<ApiProp name="low" fullType="number">
  Upper bound of the low region. Values below it are in the low region.
</ApiProp>

<ApiProp name="high" fullType="number">
  Lower bound of the high region. Values above it are in the high region.
</ApiProp>

<ApiProp name="optimum" fullType="number" defaultValue="(min + max) / 2">
  The ideal value. The region that contains it is optimum. Status colors only
  apply when at least one of `low`, `high`, or `optimum` is set.
</ApiProp>

<ApiProp
  name="getAriaValueText"
  fullType="(formattedValue: string, value: number, status: MeterStatus | undefined) => string"
  simpleType="function"
>
  Text for screen readers in place of the formatted value. Extends Base UI's
  callback with the threshold `status`, which is `undefined` without thresholds.
</ApiProp>

</ApiPropsList>

#### MeterTrack

<ApiPropsList>

<ApiProp name="segments" fullType="number">
  Split the track into this many equal blocks separated by gaps.
</ApiProp>

</ApiPropsList>

### Data Attributes

| Attribute        | Element | Description                                                   |
| ---------------- | ------- | ------------------------------------------------------------- |
| `data-status`    | Root    | `optimum`, `suboptimum`, or `critical` when thresholds apply. |
| `data-size`      | Root    | The current `size`.                                           |
| `data-segmented` | Track   | Present when `segments` is greater than 1.                    |

### CSS Variables

| Variable              | Element | Description                                           |
| --------------------- | ------- | ----------------------------------------------------- |
| `--meter-color`       | Root    | Indicator color, set from `data-status`.              |
| `--meter-segment-gap` | Track   | Width of the gap between segments. Defaults to `3px`. |
