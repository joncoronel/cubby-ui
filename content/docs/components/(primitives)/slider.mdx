The slider lets users pick a value, or a range, by dragging a thumb along a track. Use it for volume, brightness, price ranges, and other continuous settings where quick adjustment matters more than typing an exact number.

## Composition

```text
Slider
├── SliderLabel
└── SliderValue
```

`SliderLabel` and `SliderValue` are optional children that render **above** the track, so a header row (the label and value side by side) sits directly above the slider control:

```tsx
<Slider defaultValue={[50]}>
  <div className="flex items-center justify-between">
    <SliderLabel>Volume</SliderLabel>
    <SliderValue />
  </div>
</Slider>
```

For content _below_ the track, render it as a sibling of `Slider` rather than a child (for example, a `<FieldDescription>` inside the enclosing `<Field>`).

### With Steps

Use `step` to snap to discrete values, and `showSteps` to mark them on the track. To allow finer values than the marks show, leave `step` small and set `markStep` to space the marks further apart. Pass `showSteps="hover"` to show the marks only while the slider is hovered, focused, or dragged. However coarse the step, dragging follows the pointer smoothly and the thumb settles onto the nearest step when released.

### Variants

Use `variant` to change the slider's visual style.

<ComponentPreview component="slider" example="slider-variant" />

| Variant       | Description                                                                                                                                    |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `default`     | A round thumb centered on the track.                                                                                                           |
| `inset`       | A tall track with a handle that sits inside the fill.                                                                                          |
| `bar`         | A tall track with a thin bar handle and optional `startLabel` and `endLabel` text. The fill ends at the value, with the handle just inside it. |
| `squareThumb` | A square thumb in place of the round default.                                                                                                  |

### Bar With Value

The `bar` variant's labels are optional and take any node. Pass `SliderValue` as `endLabel` to show the live value inside the track; it picks up the track's text style and changes color under the fill. Format it with the slider's `format` prop. The labels are decorative, so still name the slider with `getAriaLabel` or a `SliderLabel`.

<ComponentPreview component="slider" example="slider-bar-value" />

### Color

Use `color="primary"` to fill the range with the brand color instead of the default emphasis grey that checked checkboxes, radios, and switches share.

## Accessibility

The slider is operable from the keyboard: focus a thumb, then use the arrow keys to adjust by `step`, `Home`/`End` to jump to the min and max, and `PageUp`/`PageDown` for larger increments.

Give the slider an accessible name when there is no visible `SliderLabel`. For a range slider, use `getAriaLabel` so each thumb gets its own label.

```tsx showLineNumbers
<Slider
  defaultValue={[20, 60]}
  getAriaLabel={(index) => (index === 0 ? "Minimum price" : "Maximum price")}
/>
```

## API Reference

### Slider

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "inset" | "bar" | "squareThumb"'
  simpleType="string"
  defaultValue='"default"'
>
  Sets the visual style. `inset` is a tall track with the handle inside the
  fill; `bar` is a tall track with a thin bar handle and room for labels;
  `squareThumb` swaps the round thumb for a square one.
</ApiProp>

<ApiProp
  name="color"
  fullType='"neutral" | "primary"'
  simpleType="string"
  defaultValue='"neutral"'
>
  Sets the fill of the selected range. `neutral` is the emphasis grey shared by
  selection controls; `primary` is the brand fill.
</ApiProp>

<ApiProp name="getAriaLabel" fullType="((index: number) => string) | null">
  A function that returns an accessible name for each thumb. Use for sliders
  without a visible label, or for range sliders where each thumb needs a
  distinct label.
</ApiProp>

<ApiProp name="showSteps" fullType='boolean | "hover"' defaultValue="false">
  Marks each step on the track. `"hover"` shows the marks only while the slider
  is hovered, focused, or dragged. The `inset` variant marks every step, with
  lighter marks on the fill; the others skip the ends, where the thumb sits.
</ApiProp>

<ApiProp name="markStep" fullType="number">
  The spacing between marks, in value units. Defaults to `step`. Set it wider
  than `step` to mark the scale without snapping to the marks.
</ApiProp>

<ApiProp name="startLabel" fullType="React.ReactNode">
  Optional content inside the track at its start, such as "Low" or a setting
  name. Turns the fill's foreground color where the fill covers it. `bar`
  variant only.
</ApiProp>

<ApiProp name="endLabel" fullType="React.ReactNode">
  Optional content inside the track at its end, such as "High" or a
  `SliderValue`. Turns the fill's foreground color where the fill covers it.
  `bar` variant only.
</ApiProp>

<ApiProp name="min" fullType="number" defaultValue="0">
  Minimum value of the slider range.
</ApiProp>

<ApiProp name="max" fullType="number" defaultValue="100">
  Maximum value of the slider range.
</ApiProp>

</ApiPropsList>

### Additional Props

Slider inherits all props from [Base UI Slider](https://base-ui.com/react/components/slider#api-reference), including orientation, step, value, defaultValue, onChange, and accessibility props. The exception is `thumbAlignment`, which the variant sets.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                              | Now                                                                              |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| Range and thumb in the primary blue | A `color` prop, `neutral` by default. Pass `color="primary"` for the brand fill. |
| `variant="contained"`               | Removed. Use `variant="inset"`, a tall track with the handle inside the fill.    |
