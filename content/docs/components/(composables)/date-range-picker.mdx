The date range picker is a field that opens a calendar popover for choosing a start and end date. Use it for report ranges, booking windows, and date filters. Two months sit side by side on wider screens, the band previews the range as you move toward its end, and a status line under the calendar reads back the range and its length.

To select a single date, use [`DatePicker`](/docs/components/date-picker) instead.

## Examples

The value only changes once both ends are picked. Closing the popover halfway through leaves the previous range in place.

### Typing a Range

Set `editable` to make the field a text input. It reads two dates joined by a dash, "to", or "until" ("mar 3 – 12", "today to fri", "Dec 28 – Jan 4"), relative spans like "last 30 days" or "next 2 weeks", and a single date as a one-day range. The second date borrows a missing month or year from the first, so the field also reads back its own "Oct 1 – 8, 2026". The hint shows the range and its length before it's committed, and explains a range that breaks `minNights`, `maxNights`, or a blocked date.

### Minimum and Maximum Length

`minNights` and `maxNights` limit the length of the range, counted as nights between the two ends. `minDate` and `maxDate` limit where it can fall. For stays, `labels.duration` can count nights instead of days in the status line.

## Accessibility

The trigger is a button that opens the calendar in a popover and moves focus into it. Use the arrow keys to move between days and `Enter` or `Space` to set the start and then the end; the preview band follows keyboard focus as well as the pointer. The status line under the calendar is a polite live region, so each step ("pick an end date", then the finished range and its length) is announced. `Escape` closes the popover without a change.

## API Reference

The DateRangePicker composes [`Calendar`](/docs/components/calendar) in `range` mode inside a [`Popover`](/docs/components/popover), with a trigger styled like an [`Input`](/docs/components/input). Props not listed below (`id`, `aria-*`, event handlers) go to the trigger button.

  Whether the popover is open. Pair with `onOpenChange`, or use `defaultOpen`.
</ApiProp>

  name="onOpenChange"

  simpleType="function"

  Fires when the popover opens or closes.

<ApiProp
  name="placeholder"
  fullType="string"
  defaultValue='"Pick a date range"'
>
  Text shown on the trigger when no range is selected.
</ApiProp>

<ApiProp
  name="format"
  fullType="(range: { from: Date; to: Date }) => string"
  simpleType="function"
>
  Writes the range on the trigger and in the status line. Defaults to the
  locale's compact range.
</ApiProp>

<ApiProp name="editable" fullType="boolean" defaultValue="false">
  Makes the field a text input that reads typed ranges, with the calendar on a
  button beside it. Rest props go to the input instead of the trigger.
</ApiProp>

<ApiProp name="clearable" fullType="boolean" defaultValue="false">
  Shows a button that clears the range.
</ApiProp>

<ApiProp name="minDate" fullType="Date">
  Earliest selectable date. Also stops navigation before its month.
</ApiProp>

<ApiProp name="maxDate" fullType="Date">
  Latest selectable date. Also stops navigation after its month.
</ApiProp>

<ApiProp name="disabledDates" fullType="Matcher | Matcher[]">
  Extra dates to block, as DayPicker matchers. A range can't span a blocked
  date; picking across one restarts the range.
</ApiProp>

<ApiProp name="minNights" fullType="number">
  Shortest allowed range, in nights between the ends.
</ApiProp>

<ApiProp name="maxNights" fullType="number">
  Longest allowed range, in nights between the ends.
</ApiProp>

<ApiProp name="numberOfMonths" fullType="number">
  Months shown side by side. Defaults to 2 from the `sm` breakpoint up, 1 below
  it.
</ApiProp>

<ApiProp
  name="presets"
  fullType="{ label: string; value: DateRangeValue | (() => DateRangeValue) }[]"
  simpleType="array"

  One-click ranges shown beside the calendar. Picking one commits it and closes
  the popover.
</ApiProp>

<ApiProp name="name" fullType="string">
  Submits the ends as `YYYY-MM-DD` under `${name}From` and `${name}To` in a

</ApiProp>

<ApiProp
  name="variant"
  fullType='"default" | "elevated"'

>
  Trigger background. Use `elevated` inside cards and dialogs, matching `Input`.
</ApiProp>

<ApiProp name="size" fullType='"default" | "sm"' defaultValue='"default"'>
  Trigger height, matching `Input`.
</ApiProp>

<ApiProp name="disabled" fullType="boolean" defaultValue="false">
  Prevents the popover from opening.
</ApiProp>

<ApiProp name="calendarProps" fullType="Partial<PropsBase>" simpleType="object">

</ApiProp>

<ApiProp
  name="labels"
  fullType="Partial<DateRangePickerLabels>"
  simpleType="object"
>
  Copy overrides for the picker's own text, merged over English defaults.
  Strings: `chooseDates`, `clear`, `presets`, `pickStart`, `invalid`,
  `unavailable`. Functions: `pickEnd(start)`, `duration(days)`,
  `tooShort(minNights)`, `tooLong(maxNights)`. `duration` counts both ends;
  return `days - 1` nights for stays.
</ApiProp>

<ApiProp name="className" fullType="string">
  Classes for the root element. Use a width utility to size the field.
</ApiProp>
