A horizontal bar of top-level menus, like the File / Edit / View bar in a desktop app. Use it for application-style command surfaces where several menus sit side by side and moving between them keeps the next menu open. For a single menu opened from one button, use [Dropdown Menu](/docs/components/dropdown-menu) instead.

## Composition

```text
Menubar
└── MenubarMenu          (one per top-level menu)
    ├── MenubarTrigger
    └── MenubarContent
        ├── MenubarGroup
        │   └── MenubarGroupLabel
        ├── MenubarLabel
        ├── MenubarItem
        ├── MenubarLinkItem
        ├── MenubarCheckboxItem
        ├── MenubarRadioGroup
        │   └── MenubarRadioItem
        ├── MenubarShortcut   (inside an item)
        ├── MenubarSeparator
        └── MenubarSub
            ├── MenubarSubTrigger
            └── MenubarSubContent
```

## API Reference

The Menubar component is built on top of [Base UI's Menubar](https://base-ui.com/react/components/menubar). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Menubar documentation](https://base-ui.com/react/components/menubar).

### Custom Props

#### Menubar

The bar element itself is a subtle inline toolbar that sits visibly elevated above the page.

<ApiPropsList>

<ApiProp name="level" fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8" defaultValue="2">
  Surface elevation level for the bar. Defaults to `2`, a subtle toolbar that
  lifts gently from the page. See the [Surfaces](/docs/getting-started/surfaces)
  docs.
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  defaultValue="2"
>
  Shadow weight for the bar.
</ApiProp>

</ApiPropsList>

#### MenubarContent

<ApiPropsList>

<ApiProp
  name="align"
  fullType='"start" | "center" | "end"'
  simpleType="string"
  defaultValue='"start"'
>
  How to align the menu. Flattened from Positioner. Base UI defaults to
  `'center'`.
</ApiProp>

<ApiProp name="alignOffset" fullType="number" defaultValue="-4">
  Offset along alignment axis. Flattened from Positioner.
</ApiProp>

<ApiProp name="sideOffset" fullType="number" defaultValue="8">
  Distance in pixels for positioning. Flattened from Positioner. Base UI
  defaults to `0`.
</ApiProp>

<ApiProp name="level" fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8" defaultValue="3">
  Surface elevation level for the dropdown popup.
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  defaultValue="3"
>
  Shadow weight for the dropdown popup.
</ApiProp>

</ApiPropsList>

#### MenubarSubContent

<ApiPropsList>

<ApiProp name="level" fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8" defaultValue="5">
  Surface elevation level. Submenus default to `5` so they pop above the parent
  menu.
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  defaultValue="3"
>
  Shadow weight. Kept at `3`, since submenus are still small popups.
</ApiProp>

</ApiPropsList>

#### MenubarItem

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

<ApiProp
  name="variant"
  fullType='"default" | "destructive"'
  simpleType="string"
  defaultValue='"default"'
>
  Visual style variant for dangerous actions. Custom prop not available in Base
  UI.
</ApiProp>

</ApiPropsList>

#### MenubarLinkItem

Menu item that renders as an anchor (`<a>`) for navigation links. Wraps Base UI's `Menu.LinkItem`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

</ApiPropsList>

#### MenubarCheckboxItem

Toggleable menu item. Wraps Base UI's `Menu.CheckboxItem`. The indicator sits in a reserved column on the right.

<ApiPropsList>

<ApiProp
  name="indicator"
  fullType='"check" | "switch"'
  simpleType="string"
  defaultValue='"check"'
>
  Indicator style. `"switch"` renders a decorative switch in place of the
  checkmark. It is purely visual: the item keeps the `menuitemcheckbox` role,
  the same props, and the same behavior. Custom prop not available in Base UI.
</ApiProp>

<ApiProp
  name="switchShape"
  fullType='"circle" | "pill" | "squircle"'
  simpleType="string"
  defaultValue='"circle"'
>
  Thumb silhouette, when `indicator="switch"`. Forwarded to
  [Switch](/docs/components/switch). Custom prop not available in Base UI.
</ApiProp>

<ApiProp
  name="switchSize"
  fullType='"xs" | "sm" | "default"'
  simpleType="string"
  defaultValue='"xs"'
>
  Thumb size, when `indicator="switch"`. The default matches the row's text.
  Custom prop not available in Base UI.
</ApiProp>

<ApiProp
  name="switchMotion"
  fullType='"default" | "stretch"'
  simpleType="string"
  defaultValue='"default"'
>
  What the thumb does while toggling, when `indicator="switch"`. `"stretch"`
  sends the leading edge first, so the thumb spans the track mid-toggle. Custom
  prop not available in Base UI.
</ApiProp>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

</ApiPropsList>

#### MenubarRadioItem

Mutually exclusive menu item. Wraps Base UI's `Menu.RadioItem`. Uses the same right-aligned checkmark as `MenubarCheckboxItem`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

</ApiPropsList>

#### MenubarLabel

Standalone label. Renders a plain `div`, so it can sit anywhere inside `MenubarContent`.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

</ApiPropsList>

#### MenubarGroupLabel

Label for a `MenubarGroup`. Wraps Base UI's `Menu.GroupLabel`, which names the group for assistive tech. It must have a `MenubarGroup` ancestor. Use `MenubarLabel` for a label that is not attached to a group.

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

</ApiPropsList>

#### MenubarSubTrigger

<ApiPropsList>

<ApiProp name="inset" fullType="boolean">
  Add left padding to align with items that have icons. Custom prop not
  available in Base UI.
</ApiProp>

</ApiPropsList>

### Modified Defaults

Our implementation changes the following Base UI prop defaults:

- **MenubarTrigger**: `delay` defaults to `0` (Base UI defaults to `600`)
- **MenubarTrigger**: `closeDelay` defaults to `0`
- **MenubarContent**: `align` defaults to `'start'` (Base UI defaults to `'center'`)
- **MenubarContent**: `alignOffset` defaults to `-4`
- **MenubarContent**: `sideOffset` defaults to `8` (Base UI defaults to `0`)
- **MenubarSubContent**: `sideOffset` defaults to `8`
