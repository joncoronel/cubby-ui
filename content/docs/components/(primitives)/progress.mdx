A progress bar shows how far along a task is, from start to completion. Use it for uploads, downloads, exports, or any work you can measure; pass `value={null}` while you can't measure it yet. For a static reading within a fixed range, use [`Meter`](/docs/components/meter) instead.

## Composition

```text
ProgressRoot
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    ├── ProgressBuffer
    └── ProgressIndicator
```

For a ring, swap the track for `ProgressCircle`:

```text
ProgressRoot
├── ProgressCircle
│   └── ProgressValue
└── ProgressLabel
```

`ProgressRoot` lays its children out on a grid: the label and value share the first row, and the track (plus anything else you add, like helper text) spans the full width below. No wrapper element is needed.

## Examples

### Sizes

Use `size` to set the track thickness.

<ComponentPreview component="progress" example="progress-sizes" />

| Value | Description                         |
| ----- | ----------------------------------- |
| `sm`  | 4px track for dense lists and rows. |
| `md`  | The default 6px track.              |
| `lg`  | 10px track for a focal task.        |

### Variants

Use `variant` to color the indicator with a status token.

<ComponentPreview component="progress" example="progress-variants" />

### Indeterminate

Pass `value={null}` while the amount of work is unknown. The indicator sweeps across the track; with reduced motion it breathes in place instead.

<ComponentPreview component="progress" example="progress-indeterminate" />

### Upload Lifecycle

Move from indeterminate to determinate to a `success` variant to walk a task from connecting to done. Width and color changes ease between values on their own.

<ComponentPreview component="progress" example="progress-lifecycle" />

### Buffer

Set `buffer` on the root and add `ProgressBuffer` inside the track to show a secondary value behind the indicator, like how much of a stream has loaded.

<ComponentPreview component="progress" example="progress-buffer" />

### Circle

Use `ProgressCircle` in place of the track where a bar won't fit. Put a `ProgressValue` inside it to center the value; its text scales with the ring. With a ring, the root lays its children out in a row, so a label sits beside it. At `value={null}` a quarter arc spins, which makes a small ring a drop-in spinner.

<ComponentPreview component="progress" example="progress-circle" />

### Attachment List

Small rings fit inline in rows. Each file waits as queued, uploads, then switches to `success`.

<ComponentPreview component="progress" example="progress-circle-attachments" />

### Custom Range and Format

Set `min` and `max` for a range other than 0 to 100, and pass `Intl.NumberFormat` options to `format`. `ProgressValue` takes a render function for full control over the text.

## API Reference

The Progress component is built on top of [Base UI's Progress](https://base-ui.com/react/components/progress). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Progress documentation](https://base-ui.com/react/components/progress).

### Data Attributes

| Attribute            | Element       | Description                             |
| -------------------- | ------------- | --------------------------------------- |
| `data-indeterminate` | Base UI parts | Present while `value` is `null`.        |
| `data-progressing`   | Base UI parts | Present while the value is below `max`. |
| `data-complete`      | Base UI parts | Present once the value reaches `max`.   |
| `data-size`          | Root          | The current `size`.                     |
| `data-empty`         | Root          | Present while the value equals `min`.   |

The state attributes land on the Base UI parts: root, track, indicator, label, and value. `ProgressBuffer` and `ProgressCircle` are plain elements, so style them from the root with `group-data-complete/progress:` and similar.

### CSS Variables

| Variable             | Element | Description                                      |
| -------------------- | ------- | ------------------------------------------------ |
| `--progress-color`   | Root    | Indicator and buffer color, set by `variant`.    |
| `--progress-buffer`  | Root    | The `buffer` value as a percentage of the track. |
| `--progress-percent` | Root    | The value as a unitless 0 to 100 number.         |
