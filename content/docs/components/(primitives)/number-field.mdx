A number field holds a value people can type, step with buttons or the arrow keys, or drag. Use it for bounded quantities like counts, prices, and percentages, where the value must stay a number. For a read-only value between buttons, use [`ButtonGroupText`](/docs/components/button-group#with-text).

## Composition

```text
NumberField
├── NumberFieldScrubArea
│   └── NumberFieldScrubAreaCursor
└── NumberFieldGroup
    ├── NumberFieldDecrement
    ├── NumberFieldInput
    ├── NumberFieldIncrement
    ├── NumberFieldStepper
    └── NumberFieldScrubArea
```

The group is one field-colored shell. The input and the steppers fill it, with their fills 2px in from each edge, and one focus ring wraps the whole field while you type.

`NumberFieldDecrement` and `NumberFieldIncrement` render minus and plus icons unless you pass your own. `NumberFieldStepper` replaces both with stacked chevrons on the trailing edge.

### Size

Set `size` on `NumberFieldGroup`. Heights match `Input`, so the field lines up with other fields in a form.

<ComponentPreview component="number-field" example="number-field-size" />

The shell's corners match an `Input` of the same size, and the steppers' corners are those minus the border and the 2px inset, so the two stay concentric and both follow `--radius`. Set `[--radius:9999px]` on the group for a pill.

```tsx
<NumberFieldGroup className="[--radius:9999px]">…</NumberFieldGroup>
```

## Accessibility

The input is a `spinbutton`. Arrow keys step by `step`, Shift with an arrow steps by `largeStep`, and Alt with an arrow steps by `smallStep`. Home and End jump to `min` and `max`.

The steppers stay out of the tab order, since the arrow keys already step the value, and carry the labels "Decrease" and "Increase". Holding one down repeats the step.

Label the field with `Label` or `FieldLabel`. With an inline scrub prefix, give the input its own `aria-label`.

## API Reference

The Number Field is built on [Base UI's Number Field](https://base-ui.com/react/components/number-field) and supports all of its props. Below are the parts and the props this implementation adds.

### Props

#### NumberField

Holds the value and state. Renders a `div`. Accepts `value`, `defaultValue`, `onValueChange`, `onValueCommitted`, `min`, `max`, `step`, `smallStep`, `largeStep`, `snapOnStep`, `format`, `allowWheelScrub`, `name`, `required`, `disabled`, `readOnly`, and the rest of Base UI's Root props.

#### NumberFieldGroup

The shell around the input and steppers. Renders a `div`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "elevated"'
  simpleType="string"
  defaultValue='"default"'
>
  The fill. `default` is opaque for the page; `elevated` is translucent for
  Cards, Dialogs, and popovers, as on `Input`.
</ApiProp>

<ApiProp
  name="size"
  fullType='"default" | "sm"'
  simpleType="string"
  defaultValue='"default"'
>
  Outer height, matching `Input`.
</ApiProp>

</ApiPropsList>

#### NumberFieldInput

The value. Renders an `input` with tabular numerals, centered between steppers and left-aligned after an inline scrub prefix. Set its width with `className`.

#### NumberFieldDecrement

Steps the value down. Renders a `button` with a minus icon, or your `children`.

#### NumberFieldIncrement

Steps the value up. Renders a `button` with a plus icon, or your `children`.

#### NumberFieldStepper

Stacked increment and decrement chevrons for the trailing edge. Renders a `div`.

#### NumberFieldScrubArea

Drag horizontally to change the value. Renders a `span`. Outside the group it wraps a label; inside it, it's a quiet prefix.

#### NumberFieldScrubAreaCursor

Replaces the pointer while scrubbing. Renders a `span` with a two-way arrow, or your `children`.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                            | Now                                                                              |
| ------------------------------------------------- | -------------------------------------------------------------------------------- |
| Bordered input fused between bordered buttons     | One shell with the input and quiet steppers inside. Remove any per-part borders. |
| Steppers needed an icon child                     | Minus and plus by default. Existing icon children still work.                    |
| `NumberFieldScrubAreaCursor` needed an icon child | A two-way arrow by default.                                                      |
| `NumberFieldInput` was `w-24`                     | `w-16`. Pass a width for formatted values, like `className="w-24"` for currency. |
