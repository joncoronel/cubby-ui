### Outline Variant

`default` is a filled translucent tint that reads on the page, a Card, a Dialog, or a popover alike, so the field never needs a per-surface switch. Use `variant="outline"` when you want the outline Button's fill and edge instead: a card fill with a hairline border in light mode, and a recessed fill with a faint ring in dark mode.

## API Reference

The Input component is built on top of [Base UI's Input](https://base-ui.com/react/components/input). All Base UI props are supported. The documentation below only covers custom props specific to our implementation.

For the complete Base UI API, see the [Base UI Input documentation](https://base-ui.com/react/components/input).

### Props

<ApiPropsList>

<ApiProp
  name="size"

  simpleType="string"

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                               | Now                                                                                                              |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `variant="elevated"` for fields on Cards and Dialogs | Removed. The default fill is now a translucent tint that reads on the page, a Card or a popup, so drop the prop. |
| One filled style                                     | `variant="outline"` adds a bordered style, matching the outline Button.                                          |
