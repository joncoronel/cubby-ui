An input group puts icons, text, and buttons inside a field's border, like a search icon, a unit suffix, or a show-password button. Buttons sit in the field's corners with an even 2px gap.

For a number with step buttons, use [`NumberField`](/docs/components/number-field). To join a field to buttons outside it, use [`ButtonGroup`](/docs/components/button-group#attached).

## Composition

```text
InputGroup
├── InputGroupInput (or InputGroupTextarea)
└── InputGroupAddon
    ├── InputGroupButton
    └── InputGroupText
```

Set each addon's side with `align`; a button on an inline addon's outer edge fits into the field's corner.

### Outline Variant

Use `variant="outline"` to match the outline Button: a card fill with a hairline border in light mode, a recessed fill with a faint ring in dark mode. The `default` tint already reads on the page, Cards, Dialogs, and popovers, so no field needs a per-surface variant.

<ComponentPreview component="input-group" example="input-group-outline" />

| Variant   | Description                                   |
| --------- | --------------------------------------------- |
| `default` | A translucent tint that reads on any surface. |
| `outline` | The outline Button's fill and hairline edge.  |

## Accessibility

### Labels

The group renders `role="group"`; label the input itself with `Label` or `FieldLabel`. Give every icon-only button an `aria-label`.

### Addons

Clicking an addon's icon or text focuses the input or textarea; its buttons and links keep their own focus. Addon text isn't part of the input's name, so repeat a unit like "kg" in the label if it matters.

## API Reference

Input Group is a custom component built from plain HTML elements and [`Input`](/docs/components/input), [`Textarea`](/docs/components/textarea), and [`Button`](/docs/components/button); every prop below is specific to it. Each part also accepts the props of what it renders.

### Props

#### InputGroup

The field's border and fill. Renders a `div` with `role="group"`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "outline"'
  simpleType="string"
  defaultValue='"default"'
>
  Sets the shell's fill. `default` is a translucent tint that reads on any
  surface; `outline` uses the outline Button's fill and hairline edge.
</ApiProp>

<ApiProp
  name="size"
  fullType='"default" | "sm"'
  simpleType="string"
  defaultValue='"default"'
>
  Outer height, matching `Input`. A group with a textarea or a block addon grows
  to fit.
</ApiProp>

</ApiPropsList>

#### InputGroupAddon

Icons, text, or buttons beside the input. Renders a `div`.

<ApiPropsList>

<ApiProp
  name="align"
  fullType='"inline-start" | "inline-end" | "block-start" | "block-end"'
  simpleType="string"
  defaultValue='"inline-start"'
>
  Side of the input: before, after, above, or below.
</ApiProp>

</ApiPropsList>

#### InputGroupButton

A button for an addon. Wraps [`Button`](/docs/components/button).

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"primary" | "primary-soft" | "neutral" | "tonal" | "field" | "secondary" | "outline" | "outline-ghost" | "ghost" | "link" | "destructive" | "destructive-soft"'
  simpleType="string"
  defaultValue='"ghost"'
>
  Button's variant. `ghost` takes the label-color hover, as in Button Group.
</ApiProp>

<ApiProp
  name="size"
  fullType='"default" | "icon"'
  simpleType="string"
  defaultValue='"default"'
>
  `icon` keeps an icon-only button square. In an inline addon the button fills
  the field's height; in a block addon it's 32px tall.
</ApiProp>

</ApiPropsList>

### Notes

#### InputGroupInput / InputGroupTextarea

Wrap [`Input`](/docs/components/input) and [`Textarea`](/docs/components/textarea) without their border and fill, which the group draws.

#### InputGroupText

Muted text for an addon, like a prefix or a count. Renders a `span`.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                               | Now                                                                                        |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| The group was 2px taller than an `Input`             | It matches `Input`'s height. Set `size="sm"` to match a small one.                         |
| `InputGroupButton` sizes `xs` and `sm`               | `size="default"`.                                                                          |
| `InputGroupButton` sizes `icon_xs`, `icon_sm`        | `size="icon"`.                                                                             |
| Inline buttons floated with their own corners        | They fill the field's height with corners concentric to it; drop `rounded-full` overrides. |
| Clicking an addon focused only an input              | It focuses a textarea too.                                                                 |
| `variant="elevated"` for fields on Cards and Dialogs | Removed. The default tint works on any surface, so drop the prop.                          |
| One filled style                                     | `variant="outline"` adds a bordered style, matching the outline Button.                    |
