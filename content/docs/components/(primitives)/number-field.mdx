A number field holds a value you can type, step with buttons or arrow keys, or drag. Use it for bounded quantities like counts, prices, and percentages.

For a read-only value between buttons, use [`ButtonGroupText`](/docs/components/button-group#with-text).

## Composition

```text
NumberField
├── NumberFieldScrubArea
│   └── NumberFieldScrubAreaCursor
└── NumberFieldGroup
    ├── NumberFieldDecrement
    ├── NumberFieldInput
    ├── NumberFieldIncrement
    ├── NumberFieldStepper
    └── NumberFieldScrubArea
```

`NumberFieldStepper` replaces `NumberFieldDecrement` and `NumberFieldIncrement` with stacked chevrons on the trailing edge.

## Accessibility

### Keyboard

The input is a `spinbutton`. Arrow keys step by `step`, Shift+arrow by `largeStep`, and Alt+arrow by `smallStep`. Home and End jump to `min` and `max`.

### Steppers

The steppers stay out of the tab order, since the arrow keys already step the value. Their labels are "Decrease" and "Increase"; localize them with `aria-label`, or with `incrementProps` and `decrementProps` on `NumberFieldStepper`.

### Labels

Label the field with `Label` or `FieldLabel`. With an inline scrub prefix, give the input its own `aria-label`, since the prefix is only a symbol.

## API Reference

The Number Field is built on top of [Base UI's Number Field](https://base-ui.com/react/components/number-field). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Number Field documentation](https://base-ui.com/react/components/number-field).

### Props

#### NumberFieldGroup

The shell around the input and steppers. Wraps Base UI's `NumberField.Group`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "elevated"'
  simpleType="string"
  defaultValue='"default"'
>
  Fill of the shell. Use `elevated` on Cards, Dialogs, and popovers.
</ApiProp>

<ApiProp
  name="size"
  fullType='"default" | "sm"'
  simpleType="string"
  defaultValue='"default"'
>
  Outer height, matching `Input`.
</ApiProp>

</ApiPropsList>

#### NumberFieldDecrement / NumberFieldIncrement

Step the value down and up. Wrap Base UI's `NumberField.Decrement` and `NumberField.Increment`.

<ApiPropsList>

<ApiProp name="children" fullType="ReactNode" simpleType="node">
  The icon. Defaults to a minus or plus icon.
</ApiProp>

<ApiProp
  name="aria-label"
  fullType="string"
  defaultValue='"Decrease" / "Increase"'
>
  Accessible name of the button.
</ApiProp>

</ApiPropsList>

#### NumberFieldStepper

Stacked increment and decrement chevrons for the trailing edge. Renders a `div` around Base UI's `NumberField.Increment` and `NumberField.Decrement`; other props go to the `div`.

<ApiPropsList>

<ApiProp
  name="incrementProps"
  fullType="NumberField.Increment.Props"
  simpleType="object"
>
  Props for the increment button, like a localized `aria-label`.
</ApiProp>

<ApiProp
  name="decrementProps"
  fullType="NumberField.Decrement.Props"
  simpleType="object"
>
  Props for the decrement button, like a localized `aria-label`.
</ApiProp>

</ApiPropsList>

#### NumberFieldScrubAreaCursor

Replaces the pointer while scrubbing. Wraps Base UI's `NumberField.ScrubAreaCursor`.

<ApiPropsList>

<ApiProp name="children" fullType="ReactNode" simpleType="node">
  The cursor graphic. Defaults to a two-way arrow.
</ApiProp>

</ApiPropsList>

### Notes

#### NumberFieldInput

Wraps Base UI's `NumberField.Input`. The value uses tabular numerals, centered between steppers or left-aligned after an inline scrub prefix. Set the width with `className`, like `className="w-24"` for currency.

#### NumberFieldScrubArea

Wraps Base UI's `NumberField.ScrubArea`. Outside the group it wraps a label; inside it, it renders as a quiet prefix.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                            | Now                                                                        |
| ------------------------------------------------- | -------------------------------------------------------------------------- |
| Bordered input fused between bordered buttons     | One shell with the input and steppers inside. Remove any per-part borders. |
| Steppers needed an icon child                     | Minus and plus by default. Existing icon children still work.              |
| `NumberFieldScrubAreaCursor` needed an icon child | A two-way arrow by default.                                                |
| `NumberFieldInput` was `w-24`                     | `w-16`. Pass a width for formatted values, like `className="w-24"`.        |
