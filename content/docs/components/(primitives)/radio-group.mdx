A radio group lets the user pick exactly one option from a small, visible set. Use it when every choice should stay on screen, like a plan tier or a shipping speed. For more than a handful of options, or when the choices can stay collapsed, use [`Select`](/docs/components/select) instead.

## Composition

```text
RadioGroup
└── RadioGroupItem
```

`RadioGroup` owns the selected `value`; each `RadioGroupItem` carries its own `value` and renders the indicator.

### Tone

The selected radio fills with the neutral emphasis grey by default. Pass `tone="primary"` on `RadioGroupItem` to use the brand color instead. Set the same tone on every item in a group.

<ComponentPreview component="radio-group" example="radio-group-tone" />

### Elevated Variant

Use `variant="elevated"` on `RadioGroupItem` for a stronger tint that adapts to the substrate, so the control reads clearly on a Card, Dialog, or popover instead of collapsing into it. See the [Surfaces](/docs/getting-started/surfaces) docs.

<ComponentPreview component="radio-group" example="radio-group-elevated" />

| Variant    | Description                                                 |
| ---------- | ----------------------------------------------------------- |
| `default`  | The `bg-input` tint, for radios on the page background.     |
| `elevated` | The stronger `bg-input-elevated` tint, for raised surfaces. |

## API Reference

The RadioGroup component is built on top of [Base UI's RadioGroup](https://base-ui.com/react/components/radio-group). All Base UI props are supported. The documentation below only covers custom props specific to our implementation.

### Props

#### RadioGroupItem

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"default" | "elevated"'
  simpleType="string"
  defaultValue='"default"'
>
  Surface appearance. `default` uses the `bg-input` tint. `elevated` uses the
  stronger `bg-input-elevated` tint for use inside Card, Dialog, or popover
  surfaces. See the [Surfaces](/docs/getting-started/surfaces) docs.
</ApiProp>

<ApiProp
  name="tone"
  fullType='"neutral" | "primary"'
  simpleType="string"
  defaultValue='"neutral"'
>
  Fill color when selected. `neutral` uses the emphasis grey shared by selection
  controls. `primary` uses the brand fill.
</ApiProp>

</ApiPropsList>
