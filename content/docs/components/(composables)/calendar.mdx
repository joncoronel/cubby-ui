The calendar displays a month grid for picking a single date, a range, or several dates. Use it inline for date entry or inside a popover for a date field. It is built on React DayPicker, so all of its props pass through.

It sits on a card, with the month header grouped in a muted strip across the top. On top of DayPicker it adds a few things: the caption opens a month and year picker for jumping far away, a range shows a live preview while you pick its end, a single selection slides from day to day, and changing months animates in the direction you travel.

## Examples

The `mode` prop sets what a click selects.

| Value      | Description                     |
| ---------- | ------------------------------- |
| `single`   | One date at a time.             |
| `range`    | A start and end date.           |
| `multiple` | Any number of individual dates. |

### Date Range Selection

Use `mode="range"` to pick a start and end date. After the first click, the band follows the pointer (or keyboard focus) until you pick the end. When the second click lands, the band draws in from the first day toward that one. Clicking again once a range is complete starts a new one.

### Month and Year

Click the caption to open the month and year picker over the days: a scrolling year column beside the year's months. Picking a year changes which months show; picking a month goes there and closes the picker. Click the caption again (or press `Escape`) to close it without a change. `startMonth` and `endMonth` bound the picker as well as the arrows, which makes far-off dates like birthdays quick to reach.

<ComponentPreview component="calendar" example="calendar-month-and-year" />

### Disabled Dates

Use the `disabled` prop to block dates. It takes any DayPicker matcher: a date, an array, a `{ before }` or `{ after }` bound, a `{ dayOfWeek }` list, or a function. Disabled days are struck through.

## Accessibility

The grid follows DayPicker's keyboard model: arrow keys move between days, `PageUp` and `PageDown` change months (add `Shift` for years), `Home` and `End` jump to the start or end of the week, and `Enter` or `Space` selects.

The caption is a toggle (`aria-expanded`) for the month and year picker. Opening it moves focus to the current month; `Shift+Tab` reaches the year column, where the arrow keys, `PageUp`/`PageDown` (ten years), `Home`, and `End` change the year as they move. In the months, arrow keys move between cells and `PageUp`/`PageDown` change the year. `Escape` closes the picker and returns focus to the caption without closing a surrounding popover; picking a month moves focus back to the days.

Today is marked with a dot as well as a heavier weight, and disabled days are struck through, so neither relies on color alone. Under `prefers-reduced-motion`, every transition becomes a plain crossfade.

## API Reference

The Calendar is built on top of [react-day-picker's DayPicker](https://daypicker.dev/). All DayPicker props are supported and pass through. The documentation below covers the key props and the defaults specific to this implementation.

For the complete API, see the [react-day-picker documentation](https://daypicker.dev/api/functions/DayPicker).

### Props

#### Calendar

Month grid for selecting dates. Wraps DayPicker, forwarding all props to it.

<ApiPropsList>

<ApiProp
  name="mode"
  fullType='"single" | "multiple" | "range"'
  simpleType="string"
>
  Selection behavior. `"single"` picks one date, `"range"` picks a start and
  end, `"multiple"` picks any number of individual dates. Pair with `selected`
  and `onSelect`.
</ApiProp>

<ApiProp name="selected" fullType="Date | Date[] | DateRange | undefined">
  The currently selected date(s). Shape depends on `mode`. The calendar opens on
  the month of the first selected date.
</ApiProp>

<ApiProp
  name="onSelect"
  fullType="(selected, triggerDate, modifiers, e) => void"
  simpleType="function"
>
  Callback fired when the selection changes.
</ApiProp>

<ApiProp name="framed" fullType="boolean" defaultValue="true">
  Draws the card the calendar sits on. Turn it off when the container already is
  one; the date pickers do this, so their popover is the card.
</ApiProp>

<ApiProp name="month" fullType="Date">
  The displayed month, for controlling navigation. Pair with `onMonthChange`, or
  use `defaultMonth` to only set the starting month.
</ApiProp>

<ApiProp name="disabled" fullType="Matcher | Matcher[]">
  Dates to disable. Accepts a `Date`, an array, a range, a day-of-week matcher,
  or a predicate function.
</ApiProp>

<ApiProp name="startMonth" fullType="Date">
  The earliest month that can be shown. Also bounds the month and year picker.
</ApiProp>

<ApiProp name="endMonth" fullType="Date">
  The latest month that can be shown. Also bounds the month and year picker.
</ApiProp>

<ApiProp name="numberOfMonths" fullType="number" defaultValue="1">
  Months shown side by side. They stack below the `sm` breakpoint.
</ApiProp>

<ApiProp
  name="captionLayout"
  fullType='"label" | "dropdown" | "dropdown-months" | "dropdown-years"'
  simpleType="string"
>
  Leave unset for the clickable caption that opens the month and year picker.
  `"label"` shows a static caption; the dropdown values use DayPicker's native
  selects.
</ApiProp>

<ApiProp name="showOutsideDays" fullType="boolean">
  Renders days from adjacent months to fill the grid. Defaults to `true` for one
  month and `false` for several, where they would repeat the neighboring month.
</ApiProp>

<ApiProp name="fixedWeeks" fullType="boolean">
  Always renders six weeks, so the calendar keeps its height (and a popover
  keeps its position) as you change months. Defaults to `true` for one month and
  `false` for several, where the hidden outside days would leave blank rows.
</ApiProp>

<ApiProp name="animate" fullType="boolean" defaultValue="true">
  Animates month changes. Skipped while a day has keyboard focus, so arrowing
  across months stays instant.
</ApiProp>

<ApiProp name="resetOnSelect" fullType="boolean" defaultValue="true">
  Range mode only. Clicking after a complete range starts a new one instead of
  adjusting the old one.
</ApiProp>

<ApiProp name="footer" fullType="ReactNode" simpleType="node">
  Content rendered below the month grid, in a polite live region.
</ApiProp>

<ApiProp
  name="classNames"
  fullType="Partial<Record<UI | DayFlag | SelectionState | Animation, string>>"
  simpleType="object"
>
  Class overrides for individual DayPicker elements, merged with the default
  styling. Keys include `root`, `month_grid`, `day`, `day_button`, and others.
</ApiProp>

</ApiPropsList>

### Styling

Each day cell carries its state as data attributes, so overrides can target them directly.

| Attribute                                     | Set on                                       |
| --------------------------------------------- | -------------------------------------------- |
| `data-filled`                                 | A selected day, or either end of a range.    |
| `data-in-range`                               | Days strictly inside a range.                |
| `data-range-start`, `data-range-end`          | The two ends of a range.                     |
| `data-preview-*`                              | The provisional range while picking its end. |
| `data-today`, `data-outside`, `data-disabled` | DayPicker's own day flags.                   |

The range band colors come from `--calendar-band` and `--calendar-band-preview`, set on `[data-slot="calendar"]` in `calendar.css`.
