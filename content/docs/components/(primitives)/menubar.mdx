A menubar sets an app's top-level menus side by side, like File, Edit, and View. Once one menu is open, moving across the bar opens the next, and a highlight glides to the open menu's trigger.

For one menu opened from a button, use [`DropdownMenu`](/docs/components/dropdown-menu).

## Composition

```text
Menubar
└── MenubarMenu                (inside a MenubarFilter to enable filtering)
    ├── MenubarTrigger
    └── MenubarContent
        ├── MenubarInput           (with filtering)
        ├── MenubarEmpty           (with filtering)
        ├── MenubarList            (with filtering, wraps the items)
        ├── MenubarItem
        │   └── MenubarShortcut
        ├── MenubarLinkItem
        ├── MenubarCheckboxItem
        ├── MenubarRadioGroup
        │   └── MenubarRadioItem
        ├── MenubarGroup
        │   └── MenubarGroupLabel
        ├── MenubarLabel
        ├── MenubarSeparator
        └── MenubarSub
            ├── MenubarSubTrigger
            └── MenubarSubContent
```

Add one `MenubarMenu` per top-level menu. The parts inside `MenubarContent` are [Dropdown Menu](/docs/components/dropdown-menu)'s, under Menubar names.

## Examples

### Variants

Use `variant` to pick the shell the triggers sit on.

<ComponentPreview component="menubar" example="menubar-variants" />

| Variant    | Description                             |
| ---------- | --------------------------------------- |
| `elevated` | The default. A raised surface.          |
| `outline`  | An outline Button's fill and border.    |
| `soft`     | A secondary Button's fill.              |
| `ghost`    | No shell, for a bar in an app's header. |

### Size

Use `size` to match the bar's height to a Button of the same size.

### With Filter

Wrap a `MenubarMenu` in `MenubarFilter`, then put a `MenubarInput` above a `MenubarList` to filter items as you type, and pass `viewportClassName="p-0"` to its `MenubarContent`. The parts work the same as [Dropdown Menu's](/docs/components/dropdown-menu#with-filter). While the search field has focus, Left and Right move the text cursor rather than switching menus.

## Accessibility

### Keyboard

Tab moves focus into and out of the bar in one stop. Arrow keys move between triggers, Down or Enter opens a menu, and Left and Right move to the next menu while one is open.

### Highlight

The highlight follows the pointer, keyboard focus, and the open menu. Focus also draws a ring, so the highlight is never the only cue. With reduced motion, it jumps instead of sliding.

## API Reference

The Menubar is built on top of [Base UI's Menubar](https://base-ui.com/react/components/menubar) and [Menu](https://base-ui.com/react/components/menu). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Menubar documentation](https://base-ui.com/react/components/menubar).

### Props

#### Menubar

The shell around the triggers. Wraps Base UI's `Menubar`.

<ApiPropsList>

<ApiProp
  name="variant"
  fullType='"elevated" | "outline" | "soft" | "ghost"'
  simpleType="string"
  defaultValue='"elevated"'
>
  Shell style. `ghost` draws none.
</ApiProp>

<ApiProp
  name="size"
  fullType='"sm" | "default" | "lg"'
  simpleType="string"
  defaultValue='"default"'
>
  Outer height, matching `Button`.
</ApiProp>

<ApiProp name="highlight" fullType="boolean" defaultValue="true">
  Glides one shared highlight between triggers. With `false`, each trigger
  paints its own hover.
</ApiProp>

</ApiPropsList>

#### MenubarTrigger

Opens its menu. Wraps Base UI's `Menu.Trigger`.

<ApiPropsList>

<ApiProp name="delay" fullType="number" defaultValue="0">
  Hover delay before opening, in milliseconds. Base UI defaults to `100`.
</ApiProp>

<ApiProp name="closeDelay" fullType="number" defaultValue="0">
  Hover delay before closing, in milliseconds.
</ApiProp>

</ApiPropsList>

#### MenubarContent

The menu's popup, aligned to the start of its trigger. Composes `Menu.Portal`, `Menu.Positioner`, `Menu.Popup`, and `Menu.Viewport`. Props are forwarded to `Menu.Popup`.

<ApiPropsList>

<ApiProp
  name="align"
  fullType='"start" | "center" | "end"'
  simpleType="string"
  defaultValue='"start"'
>
  Alignment against the trigger.
</ApiProp>

<ApiProp name="alignOffset" fullType="number" defaultValue="0">
  Shift along the bar from the aligned edge, in pixels.
</ApiProp>

<ApiProp name="sideOffset" fullType="number" defaultValue="4">
  Gap between the bar and the menu, in pixels.
</ApiProp>

<ApiProp
  name="level"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  simpleType="number"
  defaultValue="3"
>
  Surface level of the popup. Raise it inside a Dialog.
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  simpleType="number"
  defaultValue="3"
>
  Shadow weight of the popup. It stays at 3 when you raise `level`, so the menu
  looks the same at any depth.
</ApiProp>

<ApiProp name="positionerClassName" fullType="string">
  Classes for the positioner, the element Base UI moves into place. Merged last,
  so it overrides the defaults, such as `duration-100` for a faster glide.
  Custom prop not available in Base UI.
</ApiProp>

<ApiProp name="viewportClassName" fullType="string">
  Classes for the padded box around the items. Pass `p-0` for a filterable menu,
  whose search field and list bring their own spacing. Custom prop not available
  in Base UI.
</ApiProp>

</ApiPropsList>

### Notes

#### Menu parts

`MenubarItem`, `MenubarCheckboxItem`, `MenubarRadioItem`, `MenubarSub`, and the other parts inside `MenubarContent` are Dropdown Menu's. See the [Dropdown Menu API](/docs/components/dropdown-menu#api-reference) for their props.

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                                             | Now                                                                                                                                                                        |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installed as `cubby-ui/menubar.tsx`                                | Installs into a `cubby-ui/menubar/` folder with `menubar.css`, and installs Dropdown Menu. Import from `@/components/ui/cubby-ui/menubar/menubar` and delete the old file. |
| `level` and `shadowLevel` on `Menubar`                             | Removed; use `variant`. `MenubarContent` keeps them.                                                                                                                       |
| `MenubarContent` defaulted to `sideOffset={8}`, `alignOffset={-4}` | `sideOffset={4}`, `alignOffset={0}`, since triggers now reach the bar's edge.                                                                                              |
| Sub-menus opened after a 100ms hover delay                         | They open at once, as in Dropdown Menu.                                                                                                                                    |
