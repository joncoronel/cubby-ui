A select lets the user pick one option (or several) from a list bound to a form field. Use it for a known, finite set of choices; for a searchable list of actions or a command palette, use [`Command`](/docs/components/command) instead.

## Composition

```text
Select
├── SelectLabel
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    └── SelectGroup
        ├── SelectGroupLabel
        ├── SelectItem
        └── SelectSeparator
```

`SelectContent` composes the portal, backdrop, positioner, and popup internally. Pass your options as `items` on `Select` and render `SelectItem` children inside `SelectContent`.

### Outline Variant

Use `variant="outline"` on `SelectTrigger` to match the outline Button: a card fill with a hairline border in light mode, a recessed fill with a faint ring in dark mode. The `default` tint already reads on the page, Cards, Dialogs, and popovers, so no field needs a per-surface variant.

<ComponentPreview component="select" example="select-outline" />

| Variant   | Description                                                 |
| --------- | ----------------------------------------------------------- |
| `default` | A translucent tint that reads on any surface.               |
| `outline` | The outline Button's fill and hairline edge.                |
| `ghost`   | Chromeless trigger that mirrors the Button `ghost` variant. |

### Ghost Variant

Use `variant="ghost"` for a chromeless trigger in toolbars and dense UI. It
mirrors the Button `ghost` variant: transparent until hovered, with the same
text color shift and held background while the popup is open. Because a ghost
trigger has no visible chrome or label, give it an explicit `aria-label` so
screen readers announce what the control chooses, not just its current value.

## API Reference

The Select component is built on top of [Base UI's Select](https://base-ui.com/react/components/select). All Base UI props are supported. The documentation below only covers custom props and modified defaults specific to our implementation.

For the complete Base UI API, see the [Base UI Select documentation](https://base-ui.com/react/components/select).

### Props

#### SelectLabel

Accessible label for the select trigger. Wraps Base UI's `Select.Label`. Renders a `<div>`: clicking it focuses the trigger without opening the popup.

#### SelectTrigger

Button that opens the dropdown when clicked. Wraps Base UI's `Select.Trigger`.

<ApiPropsList>

<ApiProp
  name="size"
  fullType="'sm' | 'default'"
  simpleType="string"
  defaultValue='"default"'
>
  Size variant of the trigger button.
</ApiProp>

<ApiProp
  name="variant"
  fullType="'default' | 'outline' | 'ghost'"
  simpleType="string"
  defaultValue='"default"'
>
  Sets the field's fill. `default` is a translucent tint that reads on any
  surface; `outline` uses the outline Button's fill and hairline edge. `ghost`
  is chromeless and mirrors the Button `ghost` variant for toolbars and dense
  UI. `default` and `outline` match the same prop on Input, Combobox, and
  Autocomplete.
</ApiProp>

<ApiProp name="hideChevronRotation" fullType="boolean" defaultValue="false">
  Disable the chevron rotation animation when the select opens.
</ApiProp>

</ApiPropsList>

#### SelectContent

Dropdown container for the option list with positioning. Composes Base UI's `Select.Positioner` and `Select.Popup`. Props are forwarded to `Select.Popup`.

<ApiPropsList>

<ApiProp name="size" fullType="'sm' | 'default'" simpleType="string">
  Match the trigger's size. Only used with `alignItemWithTrigger`, where it
  lines the items up with a small trigger; otherwise items are the same at both
  sizes.
</ApiProp>

<ApiProp name="alignItemWithTrigger" fullType="boolean" defaultValue="false">
  Align the selected item with the trigger button position. Enables native-style
  scrolling with scroll arrows.
</ApiProp>

<ApiProp
  name="fadeEdges"
  fullType="boolean | 'top' | 'bottom' | 'left' | 'right' | 'x' | 'y' | FadeEdge[]"
  defaultValue="true"
>
  Controls the fade effect on scroll edges. See
  [ScrollArea](/docs/components/scroll-area#custom-props) for all options.
</ApiProp>

<ApiProp name="scrollbarGutter" fullType="boolean" defaultValue="false">
  Reserves space for the scrollbar when content overflows, preventing layout
  shift.
</ApiProp>

<ApiProp name="persistScrollbar" fullType="boolean" defaultValue="false">
  Always show the scrollbar instead of fading it in on hover or scroll.
</ApiProp>

<ApiProp name="hideScrollbar" fullType="boolean" defaultValue="false">
  Hides the scrollbar while keeping scroll functionality.
</ApiProp>

<ApiProp name="nativeScroll" fullType="boolean" defaultValue="false">
  Use native browser scrolling with styled scrollbars instead of Base UI's
  scroll virtualization. Enables CSS scroll-driven animations for fade edges.
</ApiProp>

<ApiProp name="sideOffset" fullType="number" defaultValue="6">
  Distance between the trigger and the popup. Base UI defaults to `0`.
</ApiProp>

<ApiProp name="level" fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8" defaultValue="3">
  Surface elevation level for the popup. See the
  [Surfaces](/docs/getting-started/surfaces) docs. Uses `elevatedSurface` (rim
  on `::after`) so sticky group labels stay below the rim edge.
</ApiProp>

<ApiProp
  name="shadowLevel"
  fullType="1 | 2 | 3 | 4 | 5 | 6 | 7 | 8"
  defaultValue="3"
>
  Shadow weight. Controls drop-shadow intensity independently of substrate
  color.
</ApiProp>

</ApiPropsList>

## Upgrading

If you're reinstalling over an earlier version, check these changes:

| Before                                               | Now                                                                     |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| `variant="elevated"` for fields on Cards and Dialogs | Removed. The default tint works on any surface, so drop the prop.       |
| One filled style                                     | `variant="outline"` adds a bordered style, matching the outline Button. |
